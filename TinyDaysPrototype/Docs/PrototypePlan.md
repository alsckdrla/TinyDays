# Tiny Days Prototype

목표: 방향만 제시하면 주민이 스스로 생활하는, 오래 켜두고 싶은 작은 디오라마. Windows / Unity 2022.3.20f1 / Blender 5.2.1.

## 단계와 통과 기준

1. **정지 화면·아트 기준 — 구현·자동 검증 완료, 사용자 시각 검토 대기.** 집 2채, 창고 1채, 밭 2구역, 주민 샘플, 생활 소품, 카메라 조작 및 낮·일몰·밤 프리셋. Unity 열기·Play Mode·오류 확인, 960×540과 1280×720 화면 검토 완료. 사용자의 아트 통과 판단은 아직 받지 않음.
2. **움직이는 풍경 — 구현·자동 검증 완료, 사용자 5분 시각 관찰 대기.** 주민 6명 이동·걷기·방향 전환, 작물 흔들림·연기, 180초 연속 낮밤, 무음 환경음 구조. 300초 시뮬레이션을 통과했고, 실제 5분 관찰로 발 미끄러짐·동시 행동·조명 튐을 확인한다.
3. **자율 생활 — 구현·자동 검증 완료, 사용자 15분 시각 관찰 대기.** 작업·운반·휴식·감상 선택, 피로·개인차, 작업/휴식 예약, 경로 실패 복구, F키 선택 이유 진단을 구현했다. 900초 논리 시뮬레이션을 통과했고, 15분 무입력 관찰로 동작의 자연스러움과 진단 화면을 확인한다.
4. **생산·방향 제시 — 구현·자동 검증 완료, 사용자 시각 확인 대기.** 당근 성장→수확→운반→저장→소비, 생산·균형·여유 방향, 일시정지·배속·HUD 숨김, 식량 부족의 완만한 회복을 구현했다.
5. **작은 자율 발전 — 미구현.** 저장공간 부족 지속 시 후보 위치에 확장 1회. 실제 저장 상태 기반, 잠깐 부족할 때 확장하지 않기, 중복 판단 방지, 단계별 건설 표현.
6. **실행·저장·안정성 — 미구현.** Windows 실행 파일, 설정 및 주민·작물·식량·확장 저장/복원, 버전·안정 ID·안전한 파일 교체. 30분 무입력 및 목표 PC 2시간 실행, 확장 중 저장 복원, 작은 창 30fps 측정.

각 단계는 통과 기준과 사용자 확인 후 다음 단계로 진행한다. 4단계 통과 판단 전에는 5단계를 시작하지 않는다.

## 임시값

- 지형 28×21 Unity 단위, 주민 6명, 토끼 샘플 1종, 집 2채, 공동 창고 1채, 밭 2구역.
- 당근 형태 작물 1종, 공동 식량 시작 12 / 최대 24. 수확 상자 1개는 식량 3을 저장한다.
- 카메라 직교 크기 12.8, 확대 범위 6~19, 이동 속도 8, 이동 중심 제한 X ±8 / Z ±7.
- 기본 일몰, 180초 낮밤 순환. 주민은 피로·성향에 따라 자율 생활하며 장애물을 우회한다.
- 외형과 배치·수치는 프로토타입 한정이며 최종 기획이 아니다.

## 책임 경계

현재는 자율 생활과 이동 표현까지 구현한다. 주민 Prefab은 판단 코드 없이 교체 가능하다. 판단·예약·경로 탐색·이동·외형의 책임을 분리하고 자원과 저장은 이후 단계에 연결한다. 아직 쓰지 않는 범용 시뮬레이션 프레임워크는 만들지 않는다.

## 제외 및 검토 후보

Tiny Tidy 실내 정리, 랜덤 지형, 사계절, 복잡한 날씨·관계·직업·자원, 출산·노화, 교역·멀티플레이·여러 마을, 모바일, 오프라인 진행, Steam, 입력 통과·항상 위 창 기능은 제외. 아이·가축·비는 후보만 유지.

## 3단계 이동 보완

장애물 영역과 0.25단위 A* 경로, 충돌 예측, 성향별 양보·우회·길 선호, 정체 복구를 적용한다. 상세 설정·검증 범위는 `Navigation.md`에 기록한다. 4단계 구현 이후 사용자 확인 전에는 5단계로 넘어가지 않는다.

## 4단계 생산·방향 제시

- 공동 식량은 시작 12, 최대 24이며 수확 상자 1개를 창고에 전달하면 식량 3이 저장된다.
- 밭 2곳은 심기·성장·수확 가능 상태를 거쳐 약 70초에 자라며, 밭일은 성장을 빠르게 한다. 수확 상자가 있는 밭은 먼저 운반한다.
- 주민은 새벽마다 1개씩 소비한다. 식량 부족 때는 생산·운반을 우선하고, 작업·운반 효율은 75%, 휴식 회복은 60%가 된다. 식량이 생기면 정상으로 돌아온다.
- 하단 HUD에서 생산·균형·여유를 선택한다. `Tab`은 HUD 숨김, `Space`는 일시정지, `[`·`]`는 1×·2×·4× 속도 전환이다. `F` 진단과 `1`·`2`·`3` 조명 비교는 유지한다.
- 4단계도 사용자 시각 확인 전에는 5단계로 진행하지 않는다.
