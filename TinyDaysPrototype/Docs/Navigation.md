# 3단계 이동 보완

주민 이동은 `ResidentBrain`의 목적지 선택, `VillageNavigation`의 경로 탐색, `ResidentMotor`의 회피·회전·속도 계산, `ResidentTraffic`의 공통 시간 진행과 이동 적용으로 분리했다. 현재 이동은 XZ 평면의 고정 디오라마를 대상으로 한다.

## 동선과 장애물

- 0.25단위 격자의 8방향 A*를 사용한다. 대각선 모서리 관통을 금지하고, 안전한 직선 구간으로 경로를 단순화한다. 단순화 때문에 흙길 선호가 사라지지 않도록 비용도 비교한다.
- 건물·현관·울타리·벤치·상자·드럼통·큰 돌·관목은 생성된 메시의 지면 영역 또는 명시적 원으로 등록한다. 건물은 처마까지 포함하는 보수적인 영역이다. 창고에 붙은 표지판은 건물 영역에 포함한다. 나무는 수관 대신 줄기를 등록한다.
- 밭 내부는 통행하지 않으며, 작업 장소는 가장자리다. 운반 수거·전달과 벤치 장소는 사물 밖의 빈 공간에 배치한다. 창고 전달 자리는 서로 분리했다.
- 시작점과 행동 장소의 통행 가능 여부 및 연결성을 생성 시 검사한다. 수동 오브젝트는 `ManualEdits`에 보관하고 `NavigationObstacle`을 붙여 원 또는 사각형 크기·중심을 지정한다. 사각형은 오브젝트 회전과 스케일을 따른다.
- 장애물의 활성화·비활성화·위치·회전·크기 변경은 경로 데이터를 갱신한다. 기존 주민 몸 안으로 물체를 순간 배치하는 편집은 자동 밀어내기로 해결하지 않는다. 시작 배치는 생성 검사로 검증한다.

## 성향과 움직임

기존 부지런함·느긋함은 유지한다. 길 선호도는 주민 ID와 고정 시드로 정하며 같은 주민은 재생성 후에도 같은 값을 갖는다.

| 설정 | 기본값 / 동작 |
|---|---|
| 몸통 반경 / 장애물 여유 | 0.45 / 0.1 단위 |
| 기본 이동 속도 배율 | 1.2배; 주민별 기본 속도 차이는 유지 |
| 앞선 경로 추종 거리 | 0.8 단위 |
| 가속·감속 / 최대 회전 | 2.5 단위/초² / 150도/초 |
| 주민 탐지 / 예측 시간 | 3.5 단위 / 1.8초 |
| 흙길 / 잔디 비용 | 1 / 길 선호도에 따라 1.15~1.8 |
| 느긋한 주민의 최초 양보 | 0.6 + 1.4 × 느긋함 초 |
| 정체 판정 | 2초 동안 남은 경로가 0.2단위 이상 줄지 않음 |
| 복구 실패 / 장소 재선택 금지 | 8초 / 10초 |

- 이동 전 공통 위치·속도 스냅샷으로 충돌을 예측한다. 회피 방향은 잠시 유지하고, 정면 교행은 오른쪽을 우선한다. 선호 방향이 막히면 다른 안전한 출구를 찾는다.
- 느긋한 주민은 먼저 기다리는 선택을, 부지런한 주민은 진행 가능한 우회를 선호한다. 같은 주민에게 대기를 계속 재시작하지 않도록 재양보 간격을 둔다.
- 좁은 통로는 먼저 진입한 주민에게 우선권을 준다. 동시 진입은 느긋함과 주민 ID로 정하고, 우선권은 통과·실패·서로 멀어질 때 해제한다.
- 이동 구간뿐 아니라 제동에 필요한 거리도 검사한다. 정지 상태에서 선호 방향이 막히면 안전한 방향으로 먼저 회전한다. 접촉 후 강제 위치 밀어내기는 사용하지 않는다.
- 양보 중에는 걷기 피로가 쌓이지 않는다. 실제 이동량으로 피로를 계산하며 운반 중에는 운반 피로를 적용한다.
- F키에는 성향, 이동·양보·재탐색 이유와 재탐색 횟수가 나타난다. 선택 주민의 경로와 장애물 영역은 Scene view의 Gizmos로 확인한다.

## 검증과 관찰

- `./Tools/Rebuild.ps1 -Verify -SkipArt`: 아트 원본을 다시 출력하지 않고 Unity 장면 재생성, 재생성 보존 검사, 교행 시나리오, 900초 생활 시뮬레이션과 화면 캡처를 실행한다. Unity Editor가 닫힌 상태에서 실행한다.
- `Docs/NavigationScenarios.txt`: 정면 교행·교차·추월·정지 주민·좁은 통로·가까운 거리에서 출발, 성향별 대기, 길 선호도, 장애물 갱신 검사 결과.
- `Docs/NavigationScenarios.csv`: 재현 시나리오의 0.25초 간격 실제 이동 좌표. 화면에 표시한 보정 수치가 아닌 실제 Transform 위치다.
- `Docs/Verification.txt`: 900초 동안 주민별 네 가지 행동 완료, 이동 구간의 관통·주민 충돌, 장기 정체, 예약 해제, 기존 풍경 기능 검사 결과.
- `ObserveNavigation.Execute`: 별도의 일반 Editor Play Mode를 30초 실시간으로 실행하고 초당 10장의 카메라 캡처와 런타임 오류 기록을 남긴다. 결과는 `Docs/NavigationObservation.txt`와 `Docs/Captures/Navigation`이다. 원시 프레임은 Git에서 제외되는 `Logs/NavigationFrames`에 보관하고 MP4와 대표 화면만 기록한다.

자동 검사는 시각적 자연스러움의 최종 판단을 대신하지 않는다. 물리 키 입력과 사용자의 화면·성향 선호 확인은 별도로 남긴다. Unity 내부 크래시가 재발하면 검증 통과로 간주하지 않고 로그와 미완료 항목을 기록한다. 4단계는 시작하지 않는다.
