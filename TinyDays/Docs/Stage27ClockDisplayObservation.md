# 상단 시계·날짜 표시 검토

2026-09-17 / v0.52

- 구현: 상단 중앙에 24시간제 시각과 Day 번호를 표시한다. 메뉴 숨김 중에도 유지하며 클릭 입력이나 카메라 조작을 가로채지 않는다. v0.48에서 배경 상자를 제거하고 반투명 짙은 글자 그림자와 Day 하단 여백을 추가했다. v0.49에서 Day를 시계 바로 아래로 올리고 글자 크기를 기존 약 60%로 줄였으며, v0.50에서 약 10%, v0.51에서 2pt 추가 확대했다. v0.52에서 Day 텍스트 영역과 시계 하단 여백을 늘렸다.
- 자동 검사: `clock-day-scale-v050.log`의 `STAGE27_LIGHTING_OK` / `STAGE27_CLOCK_OK` / `STAGE27_PLAYBACK_OK` 통과. Day 1·12:00 시작, 자정의 Day 증가, 3일 연속 진행, 고정 시간의 Day 유지, 일시정지와 처음부터 Day 1 복귀를 확인했다.
- Windows: `clock-day-scale-player-v050.log`의 `RESIDENT_REVIEW_PLAYER_OK` 통과 후 1280×800 독립 실행 파일을 열었다. 이 환경에서는 게임 창을 화면으로 읽는 연결이 제공되지 않아 시계 표시·메뉴 숨김 유지와 800×600·600×900의 실제 화면 확인은 사용자 확인으로 남긴다.
- 재실행 저장과 2-7-3의 장시간·창 크기 종합 관찰은 이번 범위에 포함하지 않는다.
- **사용자 확인 대기**.
