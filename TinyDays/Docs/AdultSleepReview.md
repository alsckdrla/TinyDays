## 구현 기준

참고 `References/Anim/ref_lying-sleep_ani_01.png`. 손은 배 위에 포개며 배낭과 끈은 눕기 검토 동안 숨긴다. 기존22개 클립을 유지하고22 누운 호흡4초,23 잠들기3초,24 수면 호흡6초,25 깨어나기1.5초를 추가한다.22/24만 반복하며 기존21 누운 기준 자세는 보존한다.

`adult_rabbit_sleep.py`는 가슴의 완만한 들숨/날숨·손의 작은 동행과 선택적 눈 변형을 작성한다. 머리 접점을 중심으로 가슴을 작은 각도로 열며 머리와 골반/뒤꿈치 지지를 보존한다. 목 길이/몸 스케일을 늘리지 않는다. 상의–다리 세밀한 보완은 제외한다.

Head 기본 정점/토폴로지는 유지하고 눈/하이라이트에 `SleepEyesClosed` 형상키를 추가한다. 눈이 감기면 얇은 곡선이 되고 하이라이트는 얼굴 안쪽으로 이동한다. `SleepTiming.json`의120Hz 눈 곡선을 Unity에서 클립 시간으로 샘플링한다. 얼굴 기능이 없는 호환 모델은 눈만 생략한다. Blender 원본의 `SleepPreview.py` Text를 실행하면 현재 액션/시간을 따르는 눈 미리보기를 설치한다. 사용자 자동 스크립트 실행 보안 설정은 변경하지 않는다.

## 검토와 연결

눕기 완료→누운 호흡. `잠들기`→잠들기→수면 반복, `깨어나기`→깨어 있는 호흡. 기본 연결0.25초는 클립 길이와 별도다. 잠들거나 자는 중 복귀/이동 요청은 깨어난 뒤 진행하며 마지막 요청을 따른다. 취소는 아직 시작하지 않은 복귀/이동을 취소한다. 기존 전환이 시작된 뒤에는 끝 자세까지 마친다.

왼쪽 패널·8포즈·0.5/1×·일시정지·카메라 유지. 초기화/다른 클립/비활성화는 눈0·예약/상태 정리와 배낭 이전 표시 복원을 수행한다.
