# v0.133 물뿌리개 회피·벤치 이동

최신 v0.135는 실제 준비 발 경로 검사와 중간 착지·최대 세 걸음을 적용했다. 이번 회귀 결과는 `Logs/short135-final.log`와 `RabbitShortPreparation135Review.md`를 따른다. 아래 두 걸음 고정/계산 시간은 당시 기록이다.

갱신: 2026-10-04. 구현·자동 검사·렌더·Windows 빌드 완료. **물뿌리개 회피·잔걸음 없는 벤치 이동 사용자 확인 대기**. 경로 계산 지연은 개선 대상이다.

## 변경과 이전 검사 누락

- 이전 제어는 물뿌리개에서9cm씩 계속 후퇴하며 최대21번 후퇴 거리를 늘렸고, 꽃/흙/돌을 검사에서 제외했다. 기본 흐름에서 토끼가 화단 쪽으로 밀려난 것을 수정 전 연속 프레임으로 재현했다.
- 긴 후퇴와 고정된 뒤쪽 경유점을 제거했다. 현재 자세에서 짧은 좌우/대각선 후보와 벤치 앞 접근점을 함께 검사해 안전한 짧은 경로를 선택한다. 필요한 경우 한 쌍의 짧은 방향 정리 디딤만 사용한다.
- 화단 바닥 영역 전체를 통행 회피 영역으로 등록하고, 꽃/돌의 위쪽 실제 형상도 검사한다. 집 벽/문/벤치/보관 소품과 원본 걷기 신발·몸·배낭 범위를 함께 고려한다. 빈 머리/팔 사이 공간을 거대한 상자로 채우지 않도록 형상 범위를 나누고, 장애물 여유5cm를 유지한다.
- 출발 첫 IK 착지는 작은 상체 혼합량과 달리 다음 발 목표를 사용한다. 이를 놓치던 첫 시점 검사를 고쳐 처음부터 전체 발 디딤 범위를 확인한다. 경로의 기하학적 접선과 실제 제한된 회전 속도도 함께 검사한다.
- 벤치 도착 전 마지막65cm는 벤치와 평행한 방향으로 정리해 발을 안쪽으로 디디는 것을 피한다. 회피 경유점에서는 감속/재출발하지 않고 한 보행 시계로 이어간다. 벤치 자체 착석 준비와 기존 앉기/일어서기는 보존한다.
- 안전한 후보가 없으면 현재 위치에서 `이동 경로 막힘`으로 대기한다. 재개 시 현재 위치/방향에서 다시 검사하며, 중단 요청은 기존 감속/발 모으기를 사용한다. 눈 깜빡임/호흡 시계·자동문·카메라 조작을 유지한다.

## 검사와 확인 범위

- 기본 생활240Hz,30/60/120fps×0.5/1배,8방향×4소품 방향, 회피 준비/보행 중5개 중단 시점과 재개, 한쪽/양쪽 출구 장애물 주입을 검사한다. 완료 가능한 경로와 안전 대기를 구분하며 모든 배치의 통과를 주장하지 않는다.
- 신발의 화단 여유5cm, 기존 실제 소품/벤치 관통 검사, 접지 침범0.5mm·지지 간격5mm·고정발 이동3.5mm, 추가 하강1cm·지지 무릎 추가 굽힘10도·240Hz 보정량 변화2mm 기준을 유지한다.
- 기존 전체 생활 반복·출입·물 주기·벤치·일반/운반 회전 회귀와 원본/FBX/저장 장면 해시를 확인한다. 자동 수치·렌더·OS 입력·사용자 품질 승인을 구분한다.
- 검사 도구: Unity2022.3.20f1 배치 `-executeMethod RabbitCanAvoidanceChecks.Final`(전체 회귀), `RabbitCanAvoidanceChecks.Finish`(최종 집중 검사/렌더/빌드). 장면/모델 생성은 호출하지 않는다. 결과는 `RabbitCanAvoidance133Verification.txt`, 전체 회귀 `Logs/can133-final2.log`, 최종 코드 `Logs/can133-finish.log`를 확인한다.
- 기본 흐름240Hz와30/60/120fps×두 배속 완료. 추가 골반 하강6.068mm·무릎 굽힘4.806도·고정발 이동0.163mm·240Hz 보정 변화1.980mm로 기준을 유지했다. 기본 회피 준비는 두 걸음0.8초이며 후보 준비 이동은 최대 약24.6cm로 제한했다.
-8방향×소품4방향은19개 완료·13개 안전 대기였다. 양쪽 모두 막힌 경우 위치를 변경하지 않고 대기하며 장애물 제거 후 재개했다. 한쪽 차단은 반대 경로로 완료했고5개 중단 시점도 통과했다. 모든 배치에서 이동할 수 있다는 의미는 아니다.
- 실내/실외 전체 흐름 각각20회 누적 오차0, 일반/운반 회전160개와 기존 출입·물 주기·벤치·걷기/달리기 회귀를 통과했다. 기본 모델/파생 원본·FBX9개와 저장 장면 해시가 보존됐다.
- 실행 파일 자동 콜백 검사는 `Logs/can133-player.log`의 `WATER_BENCH_LIFE_PLAYER_OK`로 완료했다. 실제 OS 버튼/마우스 입력은 수행하지 않았다. 자동 수치/영상 확인과 사용자 자연스러움 승인은 별개다.
- 남은 문제: 해당 PC에서 경로 계산 약954ms가 측정되어 출발 전 한 프레임 지연 가능성이 있다. 형상 분할을 거칠게 하는 최적화는 기본 경로를 과잉 차단해 폐기했다. 통과한8cm 분할을 유지하며 안전 여유를 줄이지 않는다.
