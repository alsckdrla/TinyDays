# v0.26 주민 선택·포커싱 검증

## 자동 검사

Unity 2022.3.20f1 / URP 14.0.10에서 컴파일 및 `ResidentOcclusionChecks`, `InteriorOcclusionChecks` 통과. 기록은 [주민 검사](ResidentOcclusionVerification.txt), [내부 검사](InteriorOcclusionVerification.txt)에 있다.

- 전체 보기의 중앙 주민 가림 투명화 없음, 단일 클릭과 같은/다른 주민 더블클릭, 느린 클릭 구분.
- 목록 선택 후 포커싱·목록 닫힘, 6픽셀 드래그 구분·해제 시 오선택 방지, 전체 보기 복귀.
- 포커싱 대상 앞 건물 25%, 해제 후 .2초 원본 재질 복원, 포커싱 없이 물체 내부·지하 예외 유지.
- 여섯 주민의 현재 관절 표면 클릭, 불투명 장애물 뒤 클릭 차단, 비활성 장애물 제외.
- 기존 집 빈 실내·벽·지붕·상자·나무 및 주민 몸 내부, 빈 수관·울타리 공간, 개별 그룹 및 원본 재질 복구 회귀 검사.

클릭 검사는 현재 Generic 관절 표면을 월드 좌표로 계산한다. FBX 내부 단위 크기에 따른 교차 검사 오차를 보완했다. 캐릭터나 물리 충돌체를 변경하지 않는다.

## 실제 Unity Game 창

2560×1440 Game 렌더, 편집기 내 약 .86배 표시에서 직접 확인했다.

- Play 실행과 일시정지, 주민 4 단일 클릭 시 번호만 표시되고 구도 유지.
- 주민 4 더블클릭 시 가까이 포커싱.
- 주민 목록 버튼으로 6개 항목·머리 위 번호 표시, 주민 1 목록 선택 후 포커싱 및 목록 닫힘.
- 반대 구도에서 주민 1 앞의 집이 반투명, E 높이 입력으로 포커싱 해제 후 집이 불투명하게 복원됨.
- Home으로 기본 전체 보기 복귀, Play 종료 시 원본 장면 표시.

실제 증거는 `Captures/ResidentSelection/DoubleClick.png`, `List.png`, `FocusedHouseFade.png`, `ReleasedOpaque.png`다.

## 작은 창과 남은 확인

Unity 편집기의 해상도 메뉴가 열리지 않아 같은 FarmStudy를 로컬 Windows 검토 실행 파일로 빌드했다. `ResidentOcclusionChecks.BuildReviewPlayer`는 농가 장면만 `Logs/ResidentSelectionPlayer`에 출력한다. 게임 출시 빌드나 전체 품질 검증을 의미하지 않는다.

800×600 실행 창은 열렸지만 Windows 방화벽 알림이 앞을 가리고 있다. 개발 빌드 종료 후 일반 빌드로 교체했으며 네트워크·방화벽 설정은 변경하지 않았다. 사용자가 알림을 닫은 뒤 작은 창 입력·번호 클릭·드래그 해제·메뉴 숨김을 계속 확인한다. 이 항목은 아직 통과로 기록하지 않는다.

상태: **구현·자동 검사 및 주요 Game 입력 확인 / 작은 창 추가 검증 대기 / 사용자 확인 대기**.

## v0.27 메뉴 토글·전체 보기 수정 (2026-09-15)

- 자동 검사: 컴파일 및 ResidentOcclusionChecks 통과. 전체 보기 선택·목록 해제와 이후 재선택을 추가 확인했다. Windows FarmStudy 검토 빌드 성공.
- 실제 Windows 800×600: 보안 알림 없이 실행. 오른쪽 하단 동일 위치의 숨김/보기와 구도 유지, 목록 주민 1 포커싱 후 전체 보기에서 번호 해제 확인.
- 실제 최대화 창(캡처 2560×1392): 주민 4 더블클릭 포커싱 → Home 번호 해제 → 한 번 클릭 재선택으로 번호 표시와 전체 구도 유지 확인. 메뉴 숨김/보기 동일 위치·크기 및 구도 유지 확인.
- 이번 입력 검증은 실제 FarmStudy Windows 실행 파일에서 수행했으며 편집기 Game 창 재검증이나 출시 품질 전체 검증으로 기록하지 않는다. 과거 작은 창 보안 알림 대기는 이번 실행에서 해소됐다.

상태: **구현·자동 검사·실제 Windows 입력 확인 / 사용자 확인 대기**.

## v0.28 포커싱 카메라 조작 유지 (2026-09-15)

- 자동 검사: `ResidentOcclusionChecks` 통과. 6픽셀 이상 패닝이 포커싱을 해제하지 않고, 전체 보기에서 선택·목록·번호를 해제하는지 확인했다.
- 실제 Windows 800×600: 주민 1을 목록에서 포커싱한 뒤 패닝·휠 확대에도 번호와 포커싱을 유지했다. Home에서 전체 보기와 번호 해제를 확인했다.
- 실제 최대화 창: 주민 2를 목록에서 포커싱한 뒤 화면 기준 패닝을 수행해도 번호와 포커싱이 유지됐다. 주민 기준 오프셋은 다음 주민 이동에도 같은 구도를 유지하도록 구현했다.
- 포커싱 주민 앞 환경의 25% 반투명은 기존 검증 결과와 같은 포커싱 기준을 계속 사용한다. 카메라 내부·지하 예외도 변경하지 않았다.

상태: **구현·자동 검사·실제 Windows 입력 확인 / 사용자 확인 대기**.
