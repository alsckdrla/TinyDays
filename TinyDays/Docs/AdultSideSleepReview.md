# v0.111 편안한 팔베개·꼬리 고정·옆누운 수면

2026-09-29. 구현·자동 검사·렌더·Windows 빌드 완료. **팔베개·꼬리 고정·옆누운 수면 사용자 확인 대기**.

## 변경과 조작

- 왼쪽 아래팔을 볼 밑으로 더 넣고 머리에 작은 기대기/끄덕임을 주었다. 공통2.4초 전환과 토끼 전용 `SUPPORT` 설정을 분리했다. 실제 왼쪽=legacy R, 골격/메시는 그대로다. 다른 동물에서의 완전한 호환을 검증한 것은 아니다.
- 바로/옆으로 눕기와 복귀·휴식·수면의 꼬리는 **골반에 대한 바인드 부착 위치/방향**을 유지한다. 예전 골반 주변90도 이동/옆누움 반대편 이동을 제거했다. 짧은 토끼 꼬리는 지면에 들어가도 되며 바닥 회피/몸 높이 계산 대상에서 제외했다. 신체 전체의 접지 조건을 완화한 것은 아니다.
- 기존29개 참조 뒤에29 `Adult_Fall_Asleep_Left`3초,30 `Adult_Sleep_Left`6초 반복,31 `Adult_Wake_Left`1.5초를 추가했다. 잠들기/깨어나기 버튼을 바로/옆 자세가 공유하고 눈 블렌드셰이프를 재사용한다. 눈 기능이 없는 호환 모델은 몸만 재생 가능하다.
- 옆휴식28에서 **잠들기 → 옆 수면 → 깨어나기 → 옆휴식**. 자동으로 잠들지는 않는다.4초/약7.8mm와6초/약10.4mm 호흡은 위상을 이어가며 주기와 크기만 연속 변경한다. 진입 연결0.25초는3초 잠들기와 별도다.
- 잠들거나 자는 중 앉기/서기/걷기/달리기/바로눕기 요청은 현재 눈 감김에서 **옆에서 깨어나기 → 바로눕기 복귀 → 필요하면 기존 앉기/일어서기/이동**으로 연결한다. 마지막 요청 우선; 취소하면 진행 중 깨어나기는 마치고 옆휴식에 남는다. 이미 시작한 몸 전환은 끝까지 마친다.
- 옆에서 직접 앉거나 일어서기는 미제작 후속이다. 기존 왼쪽UI/카메라/배속/일시정지, 배낭/끈 숨김·복구 유지. 상의는 작은 흔들림만, 상의–다리 미세 관통은 검사/보완하지 않는다. 농가/GitHub 작업 없음.

## 보존과 재현

- 원본 백업 `Logs/BeforeV0111`, 이전Unity자료 `Captures/SideBeforeV0111`. 동일Blender3D카메라 전후/좌우표식 `Captures/SideDirectionV0111`; 새Unity/비교영상은 `Captures/SideRest`, `Captures/SideSleep`.
- `verify_sitting_preservation.py --v0111`:0~16번 액션 전체,17~25번은 허용한Tail채널만 제외한 나머지 전체, 기본 메시/바인드 해시 일치. `AdultSideSleepPreservation.txt`. 기존29개 전체가 동일하다고 기록하지 않는다.26~28은 팔베개/꼬리 변경 대상이다.
- `adult_rest_tail.fix_existing`은 기존 눕기/수면 액션의 Tail 곡선만 고친다. 전체생성기와 추가생성기 모두 같은 규칙을 사용한다. 원본/FBX/32개 audit/눈 타이밍 데이터와 Blender 미리보기는 같은 곡선을 사용한다.
- `verify_rest_tail.py`:240Hz 골반 상대 바인드 오차 검사(17~31), 꼬리 지면 침범은 허용. `verify_side_pillow.py`:새6개 옆 동작의 실제 변형된 양손/아래팔–머리 부호 거리·소매 바닥 검사. 이는 상의–다리 미세 검사가 아니며 모든 삼각형 쌍 충돌/물리 지지력을 보장하지 않는다.
- `AdultSideSleepChecks`:240Hz 꼬리 부착/지지점/호흡,480개 출발목적지 조합과48개 호흡위상·취소·배속·fps 조합. 실제 물리 입력이 아니라 함수 호출이다. `Continuous`는8개 초기위상에서14초를240Hz로 추적한다.
- 최초 검사에서 같은 이름의 메시 Transform과 Head 뼈를 혼동한 검사 오류를 뼈 배열 참조로 수정했다. 재활성화 시험에 남아 있던0.5배 설정도 명시적으로1배로 초기화했다. 검사 코드 오류를 동작 수정 완료로 포장하지 않는다.
