날짜: 2026-10-05

## 범위

- 사용자 선택과 실행 승인: 인사·짧은 대화·함께 쉬기. 읽을 수 있는 대사는 없으며, 대화는 서로 바라보는 몸짓과 교대로 나타나는 `…` 표시로만 표현한다.
- 기존 쉼터의 독립된 자리를 이용해 쉬는 두 주민을 연결한다. 혼자 쉬기/개인 여가도 유지한다. 정밀 동작이나 원본 변경 없이 현재 자세 위의 작은 고개 움직임으로 우선 검토한다.
- 인사1.4초→대화4.8초→함께 쉬기6초, 재교류 대기40~54초는 검토값이다. 이동/작업 중 강제로 붙잡지 않으며 배고픔·심한 피로·귀가·부족·비/눈에 교류를 끝낸다.
- 둘의 상대/진행·재교류 대기는 저장146에 포함한다. 이전142/144/145의 생활 상태·예약·계절·날씨·시간·구도는 유지한다. 기존 저장 원문 보존과 실패 시 덮어쓰기 차단 유지.
- 가축·관계 수치·대사·새 정밀 클립은 추가하지 않는다. 기존2단계·캐릭터 품질 보류와 출시2시간 검증은 유지한다.
