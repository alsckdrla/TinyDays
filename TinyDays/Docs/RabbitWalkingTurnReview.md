# 생활 보행의 연속 방향 전환 검토 (v0.128)

갱신: 2026-10-03. **연속 방향 전환 사용자 확인 대기**. 기존 동작의 최종 품질 승인까지 추정하지 않는다.

## 변경

- 출입·일반/물뿌리개 운반·벤치 접근에서 방향만 바꾸기 위한 정지/제자리 회전/재출발을 작은 곡선 보행으로 교체했다. 경유점마다 걷기 위상과 팔 흔들림을 초기화하지 않는다. 급한 회전에서는 부드럽게 속도를 낮춘다.
- 현재 지지발은 세계 좌표에 유지하고, 반대 발은 경로의 미래 위치·방향에 착지한다. 착지 때 미보정 클립 발 위치로 목표를 덮어쓰던 문제를 수정했다. 회전 중단은 현재 자세에서 감속/발 모으기로 이어진다.
- 정지 예측은 남은 착지/발 모으기 거리를 포함한다. 경로 끝에서 주민 위치만 강제로 멈춰 다리가 당겨지지 않도록 했다. 작업 방향이 이동 방향과 다를 때 마지막 직선 접근 구간을 둔다.
- 문 열림/닫힘 대기·집기/내려놓기·물 주기·착석 정지는 유지한다. 연결 외출은 문 닫힘 대기 후 바로 보관 소품으로 이동한다. 벤치 최종 방향 정리/뒤걸음은 착석 준비로 남아 있다.
- 보관 소품 실제 경계 여유는 물 주기까지만 재생과 벤치 연결 모두 적용한다. 기존 모델/골격/Blender/FBX/애니메이션 원본은 재생성하지 않는다. 손잡이 접촉, 호흡/깜빡임, 왼쪽 패널/배속/일시정지는 유지한다.
