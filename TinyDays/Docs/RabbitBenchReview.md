## v0.122 변경과 최신 검증

- 벤치를 폭1.5m·깊이36cm·좌판30cm,120삼각형/1재질로 변경했다. 실제 렌더 메시 경계에서 접근·회전점과 착석 준비점을 계산한다. 초기 접근은 앞쪽 안전 공간을 따라 걷고 두 걸음 회전 후 낮은 뒤걸음 한 쌍으로 준비점에 도착한다. 큰 방향 차이를 가진 재접근은 기존 최대3걸음 회전 기준을 유지한다.
- 준비점은 좌판 중심 앞32cm. 다리가 좌판 앞면과 겹치지 않게 최종 골반 위치를 시작안7cm보다 앞쪽 약12cm로 맞췄다. 먼저 좌판 앞쪽으로 몸을 낮추고 발을 들어 정리하는 동안 골반을 조금 뒤로 안정시킨다. 앉기1.8초에서 마지막0.35초에 발을 올리고, 일어서기1.8초에서 첫0.35초에 발을 내려놓는다.
- 휴식 양발 바닥은 지면 위56.10mm. 골반·공중 발을 고정하고 기존4초/14mm 가슴 호흡·배낭·두 손의 허벅지 자세를 유지한다. 공중 발은 지면 접촉 검사에서 구분하며 원래 접지 목표는 따로 보존한다.
- 기존 검사는 지면 높이만 확인해 벤치 수평 겹침을 놓쳤다. 새240Hz 검사는 신발/바지 다리 정점이 실제 벤치 닫힌 메시 내부에 들어가는지, 접근/회전의 수평 여유와 엉덩이 지지 영역이 좌판 범위 안인지 확인한다. 정점·시간 표본 검사이며 모든 연속 충돌을 보장하는 물리 시스템은 아니다. 상의–다리 미세 보완은 하지 않는다.
- 최종 측정: 접근/회전 최소 여유73.152mm, 지지 신발 최저+2.447mm·최대 간격2.554mm·고정발 이동0.163mm·다리 도달 초과0. 엉덩이–좌판 간격2.509mm, 가슴 폭14.000mm.30/60/120fps×두 배속 전체 흐름/재착석,8위상 이동·취소·초기화·모드 복원과 벤치 이동 시 앵커 동반 이동 통과(`RabbitBenchRegression.txt`, `bench122-final-reseat.log`). 원래 물 주기·출입20왕복·걷기/달리기96조합 회귀 통과(`bench122-complete.log`).
- 초안 뒤걸음 도달 초과는 점 사이 거리/감속 여유와 체중 곡선을 맞춰 해결했다. 전환 혼합이 이미 낮춰진 골반을 다시 낮추거나 발 착지보다 체중 이동을 늦추던 문제도 벤치 전환에서만 수정했다. 원래 집 출입/물 주기 `RabbitHomeFootwork` 기본값은 변경하지 않는다.

## v0.121 당시 기록 — 아래 수치는 최신 기준이 아님

## 구현과 조작

- 집 앞 왼쪽의 등받이 없는 나무 벤치. 배낭과 끈을 유지하며 문 통과/오른쪽 화단 동선을 확보한다. 좌판 높이는 검토 지면 위24.64cm, 폭1.3m이며120삼각형/1재질이다. 벤치 FBX의 축 변환은 자식 모델에 보존한다.
- 기존36개 동작 소스를 읽어 별도 `ArtSource/AdultRabbitBench.blend`와 `Assets/Art/Generated/RabbitBench/AdultRabbitBench.fbx`에 앉기1.8초(54프레임)·기본 호흡4초(120프레임)·일어서기1.8초(54프레임)를 추가했다. 일어서기는 별도 곡선이며 역재생하지 않는다.
- 발은 지면을 유지하고 골반이 뒤로22cm/아래로 이동해 좌판에 앉는다. 약한 전방 체중 이동과 두 손의 허벅지 지지를 겹쳐 연결한다. 귀·목도리·배낭에 약한 후행, 상의에 작은4초 흔들림을 적용한다. 신체 스케일과 목·팔다리 길이를 늘리지 않는다.
- `RabbitHomeLifeStudy`/`TinyDaysRabbitHomeLife.exe` 왼쪽 패널의 **벤치 휴식 검토 → 전체 흐름 · 벤치 휴식**. 접근→감속/발 모으기→두 걸음 방향 정리→앉기→6초 호흡 휴식→일어서기→약1m 목적지로 걷기/정지. 실제 최종 이동은 기존 정지 허용 영역 안에서 마친다.
- 개별 **앉기**는 접근 후 계속 앉아 호흡한다. **일어서기 / 걷기 재개 / 정지·예약 취소 / 처음 위치**, 두 배속·일시정지·세 구도·세 동작 각각8포즈를 제공한다. 포즈 선택은 명시적인 검토 위치 변경이므로 이동 접촉 검사와 구분한다.
- 앉는 중 이동 요청은 착석을 마친 뒤 일어서기/출발, 앉아 있을 때는 일어서기/출발로 연결한다. 진행 중 요청은 마지막 요청으로 예약하며 반복 요청은 재시작하지 않는다. 취소는 후속 이동을 없애고 진행 중 착석/기립은 끝 자세까지 마친다. 접근 보행은 기존 감속, 회전 취소는 회전 완료 후 대기로 연결한다.
- 모드 선택은 초기화이며 출입·물 주기·벤치 중 하나만 주민 자세를 제어한다. 벤치 모드에서는 물뿌리개/물방울과 출입 자동 왕복이 꺼진다. 종료 시 임시 상의 메시를 원래 메시로 복구한다.

## 보존과 다른 PC 재개

- 벤치 접근점·착석 방향·좌판 높이·휴식/이동 길이는 `RabbitBenchReview` 설정, 체형별 골반/손/발 위치는 별도 생성 스크립트 설정이다. 현재 성인 토끼만 검증했으며 다른 체형을 적용할 때 좌판과 접촉을 다시 맞춘다.
- 아트 생성은 Blender5.2.1의 `--background --factory-startup --python-exit-code 1 --python Tools/build_rabbit_bench_art.py`. 원래 동작/집/물 주기 소스를 덮어쓰지 않는다.
- Unity2022.3.20f1에서 `RabbitBenchChecks.Complete`는 장면 생성·벤치 검사/렌더·기존 회귀·Windows 빌드를 수행한다. 아트가 이미 있으면 `RabbitHomeLifeBuilder.BuildPlayer`만으로 해당 PC의 실행 파일을 재빌드한다. 실행 파일과 Logs 캐시는 Git 제외다.
- 이번 작업은 로컬 저장이며 GitHub 업로드를 하지 않았다. 기존 원격은 v0.120 저장 커밋 `3dca1e4`다. 다음은 벤치 피드백 확인 후 외출→물 주기→벤치 휴식을 한 생활 흐름으로 연결하는 계획이다. 새 변형·생활AI·농가 적용은 제작하지 않았다.
