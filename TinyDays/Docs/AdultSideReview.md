# v0.110 실제 왼쪽 방향·팔베개 지지 수정

2026-09-29. **왼쪽 방향·팔베개 자세 사용자 확인 대기.** v0.109는 사용자 미승인이다. 아래 v0.109 수치는 당시 검사 결과이지 올바른 좌우/팔베개 품질의 증명이 아니다.

## 이번 수정과 재현된 오류

- 얼굴이 Blender −Y를 향하므로 해부학적 왼쪽은 −X이다. 기존 골격은 반대로 명명되어 **실제 왼쪽=접미사R, 오른쪽=L**이다. 이름/바인드와 기존26개 액션을 그대로 두고 옆누움3개에만 대응을 명시했다. 회전을 반대로 하여 왼쪽 어깨/옆구리가 아래에 놓인다.
- v0.109는 손을 얼굴 옆에 옮겼으나 머리–아래팔 지지 관계를 계산하지 않았다. 이제 왼쪽 아래팔 위에 머리 옆면을 놓고 손목 방향도 맞췄다. 오른팔은 몸 앞에서 굽히고 손이 얼굴을 가리지 않도록 했다. 위쪽 오른다리는 조금 앞으로 둔다.
- 골반/몸통/머리 높이를 함께 맞추며 **머리 바닥 접촉 기준은 제거**했다. 몸통·하단 신발의 지표 지지는 유지한다. 원본 길이/스케일, 양방향2.4초/호흡4초/약7.8mm, 호흡 위상과 예약/취소 규칙은 유지한다.
- 복귀 중 왼손이 볼을 약14.6mm 통과하는 중간 초안을 검사에서 발견했다. 손을 볼 바깥으로 회수하는 곡선을 추가해 원본240Hz 검사에서 해소했다. 초기 Unity 호흡 지지점5.4187mm 이동도 실패로 기록하고, 왼손 고정+기존 팔꿈치 계산으로 보완했다. 최종 결과는 다음 항목에 기록한다.

- `Captures/SideDirectionV0110`은 같은 Blender 카메라/조명의 전후4구도와 실제 왼팔 표식 이미지다. `Captures/SideBeforeV0110`은 이전Unity이미지/영상. 최신Unity3구도와1×영상은 `Captures/SideRest`에 갱신한다. 새45/90구도는 반대 방향으로 돌아누운 얼굴을 보도록 카메라를 반대쪽으로 옮겼으므로 동일 카메라 전후 비교는0구도와 Blender 전후를 사용한다.

## 원본과 공통 호흡

- `Tools/adult_rabbit_side.py`는 고정된 골격 길이로 손/무릎을 모으고 큰 머리와 몸통이 함께 지지되는 옆누운 자세를 계산한다. 회전하는 메시의 여유 높이를 오프라인 연속 경로로 작성하며 실행 중 바닥으로 강제 스냅하지 않는다.
- `Tools/append_side_review.py`는 기존 원본 액션을 재생성하지 않고3개만 갱신한다. 전체 제작기 `animate_adult_rabbit.py`도 같은 모듈을 사용한다. Blender·FBX·audit·Unity 클립 참조/장면 보존.
- 돌아눕기 원본은 호흡이 없는 전환 기준이다. Unity에서는 기존4초 호흡 위상을 유지하고, 바로/옆누운 참조의 중립 대비 변형분을 섞어 전환 위에 적용한다. 옆누운 루프 원본은 같은 호흡 곡선을 포함한다. Blender 단일 전환 액션 재생은 runtime의 임의 시작 호흡 위상까지 재현하는 것은 아니다.
- 시작 자세의 작은 로컬 잔차는0.25초 동안 감쇠해 첫 프레임 차이를 줄인다. 명시적 클립 선택/초기화와 내부 자세 전환을 구분하고, 내부 전환에는 호흡 시계를 초기화하지 않는다.
- 배낭/끈 숨김과 종료/비활성화 복구는 기존 눕기 제어를 사용한다. 눈 감김은 옆누움에 적용하지 않는다.
