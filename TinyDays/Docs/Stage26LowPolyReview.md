# 기준 집·소품 첫 검토 — 사용자 확인 대기

2026-09-15 / Unity 2022.3.20f1 / 본게임 FarmStudy. 실제 Game 창 기록이 아닌 Unity 편집기 자동 렌더이다.

## 제작

- Home A 위치 (-5, 0, 6.5), 벽 외곽 4.3×4.0m와 주민 경로 유지. 현관은 왼쪽으로 0.25m 옮기되 기존 길과 문턱 폭 안에서 연결했다.
- 크림 회벽, 회갈색 지붕의 넓은 5구획, 밝은 두꺼운 처마, 작은 편경사 차양, 비대칭 크기의 창, 프레임 안으로 들어간 목재 문과 불투명 유리색 판을 적용했다. 창은 실제 투명 유리 셰이더가 아니다.
- 벽은 개구부 주변을 채우는 방식이며 프레임은 네 변으로 제작했다. 맞배지붕 판·밑면·처마·삼각 벽·굴뚝 마감을 닫힌 메시로 제작했다. 실내 생활 공간 제작은 이번 범위가 아니다.
- 벤치의 좌판·등받이·다리 지지대, 내부가 열린 상자의 바닥·판재·모서리, 선택적 스무스 노멀의 10각 통과 테두리·뚜껑, 울타리 기둥 모자·연결부를 제작했다. 울타리 모서리 기둥은 인접 구간끼리 소유권을 공유해 겹치지 않는다.
- 고정 부품은 원형별·재질별로 결합했다. 같은 원형의 배치들은 메시와 단색 재질을 공유한다. 가림 처리는 집/소품/울타리 구간 단위이며 벤치 때문에 쉼터 바닥까지 흐려지지 않도록 분리했다.
- Home B·Storehouse·나무·주민 외형과 카메라 입력 코드는 이번에 변경하지 않았다. 소품은 기존 위치의 동일 원형들을 교체했다.

## 전후 수치

삼각형은 MeshRenderer의 메시 인스턴스 합계이며, 재질은 해당 범위에서 사용한 고유 재질 수다. 전체 환경 수치는 주민의 SkinnedMeshRenderer를 제외한다.

| 대상 | 삼각형 전 → 후 | 렌더러 전 → 후 | 재질 전 → 후 | 예산 |
|---|---:|---:|---:|---:|
| Home A | 1,650 → 1,204 | 75 → 9 | 9 → 9 | ≤2,000 |
| 상자 원형 | 108 → 228 | 9 → 3 | 3 → 3 | ≤300 |
| 통 원형 | 320 → 236 | 4 → 3 | 3 → 3 | ≤300 |
| 벤치 원형 | 72 → 168 | 6 → 3 | 3 → 3 | ≤300 |
| 울타리 전체 | 1,368 → 1,776 | 114 → 35 | 1 → 1 | 새 구간당 24~72, ≤100 |
| 환경 전체 | 255,822 → 256,228 | 750 → 569 | 25 → 28 | 전체 예산 미합의 |

울타리 기존 구조는 개별 기둥/가로대였으므로 전체 배치끼리 비교한다. 양끝 기둥을 포함한 새 단독 구간은 72삼각형이다. 소품 디테일 증가 때문에 환경 전체 면 수는 소폭 증가했다. 기존 식물·나무와 임시 캐릭터의 최적화는 별도 범위이며 **저사양 PC 성능을 보장하거나 측정한 수치가 아니다.**

## 검증 범위와 남은 확인

- 자동 검사 통과: 컴파일, 원형별 예산, 반복 소품 메시 공유, 읽을 수 있는 메시, 퇴화 삼각형 없음, 메시 변의 짝수 연결 검사, 전면 문/창 위치에 회벽이 없는지와 실제 벽 구간의 교차 대조 검사.
- 제작 중 차양 기울기·중복 울타리 기둥을 수정했고 문 아래 부동소수점 오차로 생긴 얇은 퇴화 면은 제거했다. 닫힘 검사는 메시 부품 단위이며 전체 건물의 모든 접합 품질을 수학적으로 보증하지 않는다.
- 직접 함수 호출 검사 통과: 모든 신규 집/소품 그룹의 25% 반투명과 .2초 원본 복구. 기존 카메라 회귀 검사(지하 중심, 지하→지상, 독립 복구, 재활성화, 구도 복귀), 주민 경로/주민 간격, 재생성 두 번의 ManualEdits 보존도 통과했다.
- [새 검사 기록](Stage26LowPolyVerification.txt) / [기존 농가·카메라 회귀 기록](Stage26Verification.txt).
- 자동 렌더를 정면·측면·후면·비스듬한 구도·낮은 시점·축소 구도로 검토했다. 확인한 정지 이미지에서 문 돌출·막힌 창·큰 지붕 틈/밑면 누락은 보이지 않았다. 그림자의 톱니 모양은 남아 있으며 조명/그림자 품질은 별도 보완 대상이다.
- **실제 Game 창의 연속 회전·줌·패닝 중 깜빡임, 주민 이동과 가림/복구의 시각 관찰은 이번 작업에서 미실시**다. 자동 호출·정지 렌더를 실제 입력 검증으로 기록하지 않는다. 사용자에게 집 색감·비율·처마/차양·소품 디자인 확인을 요청한다.

## 원본과 재생성

- [메시 생성 원본](../Assets/Editor/FarmLowPolyAssets.cs), [농가 생성기](../Assets/Editor/FarmStudyBuilder.cs), [검사/촬영 도구](../Assets/Editor/FarmArtReview.cs).
- 생성 메시: `Assets/Art/Generated/FarmStudy/LowPoly/`. 이번 모델은 C# 절차적 메시 원본이며 별도의 Blender 원본을 만들었다고 기록하지 않는다.
- Unity에서 해당 프로젝트를 닫고 `Tools/RebuildFarmStudy.ps1` 실행. GeneratedFarmStudy와 생성 자산만 갱신하며 ManualEdits는 보존한다. `Before`는 최초 비교 기록, `After`는 재생성 시 갱신한다. `CaptureBefore`를 다시 호출하면 기존 비교 기록이 교체되므로 주의한다.
- 상태: **기준 집·소품 디자인 사용자 확인 대기**. 다른 집·창고 디자인 확장은 승인 후 결정한다. 커밋·푸시는 수행하지 않았다.
