# v0.44 색상 선택 검토 — 2026-09-16

- 자동 검사: `lighting-v044.log`의 최종 `STAGE27_LIGHTING_OK`. 새 스크립트 최초 가져오기 중 일시적 미발견 오류 이후 재컴파일·검사 통과. 최종 Windows 빌드는 컴파일 오류 없이 `RESIDENT_REVIEW_PLAYER_OK`.
- 일출·일몰 전체 구도 렌더의 배경 픽셀이 각각 #8A4636 / #A66A59에 RGB 채널 1 이내로 일치한다. 옛 원본 조명 수치 복구가 아니라 보존 이미지에 근거한 재조정이다.
- 사용자 PlayerPrefs 대신 메모리 저장소로 4시간대×3항목의 미리보기 미저장·확정 저장·새 인스턴스 복원·잘못된 값 기본값 처리를 검사했다. 기존 창문 팔레트·낮 발광 해제·가림 복원·수동 영역 보존 검사도 통과했다.
- 실제 Windows 1280×800: 시간대별 3개 미리보기, 일출 배경 색상창, 색상 띠 드래그, Hex 직접 입력과 즉시 배경 반영, 확인 저장을 검증했다.
- 실제 Windows 800×600 재실행: 저장한 시험값 #8B4636이 복원됨을 확인했다. RGB 입력으로 #644636에 즉시 변경한 뒤 취소 버튼으로 #8B4636 복원 확인. 기본색 복원으로 #8A4636을 되돌리고 확인 저장했다. 시험색을 남기지 않았다.
- 실제 Windows 600×900: 패널·선택창의 모든 조작부가 잘리지 않음, 일몰 기본값 #A66A59, 입력란 포커스 중 Escape 취소, 햇빛 항목 열기와 모달 밖 드래그의 카메라 차단을 확인했다. 편집 중 주민 이동은 계속된다.
- 색상창에서 풍경을 어둡게 덮지 않도록 수정했고, 입력란 글자 크기와 일출·일몰 안내 글씨 대비를 보완했다.
- 최종 1280×800 빌드에서 주변광 항목 열기·Escape 취소를 재검증했다. 취소 키가 그림자 설정창까지 전달되는 중복 입력을 보완해, 색상창만 닫히는 것을 확인했다. 독립 게임 창은 이 최종 빌드로 열어 두었다.
- UI 실제 입력은 위 대표 항목을 확인했으며 모든 12개 항목의 실제 클릭 조합을 전수 검사한 것은 아니다. 자동 순환·5분 관찰·Editor Play 확인은 이번 범위에 포함하지 않았다.
