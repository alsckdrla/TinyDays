# 물뿌리개 운반·화단 물 주기 — v0.120

## 구현

- 참고: `References/Char_Rabbit_Adult_Water_Carry_01.png`, `Char_Rabbit_Adult_Water_Pour_01.png`. 양손으로 파란 물뿌리개를 든 채 집 앞에서 시작해 약1.56m 걷기→감속/발 모으기→물 주기→운반 대기로 연결한다. 집기·내려놓기·물 채우기·출입 자동 연결은 만들지 않았다.
- 운반 대기4초, 운반 걷기0.8초·기존1.15m/s, 물 주기6초(0~1.2초 기울이기/1.2~4.4초 살수/4.4~6초 복귀). 끝 자세에서 기존 호흡으로 부드럽게 혼합하는0.5초는 클립 밖 정리 시간이다. 전체 최초 흐름은 약8.6초다.
- 상체는 운반 때 약5도 뒤로, 물 주기 때 약8도 앞으로 기울인다. 물 주기에서는 머리도 꽃 쪽을 바라본다. 기존 골격과36개 원본 클립은 그대로 두고 작업 전용 소스에3개 클립을 추가했다. 물뿌리개는512삼각형/2재질, 별도 물방울은최대96개·각8삼각형이다. 기존 캐릭터 예산과 구분한다.
- 손잡이는 몸 쪽으로8cm 치우쳐 잡기 편하게 하고, 물뿌리개를25도 기울인다. 짧은 팔이 닿지 않던 초안은 소품 배치로 수정했으며 팔 길이를 늘리지 않는다. Unity에서 실제 어깨의 좌우를 읽어 손잡이 대응을 정한다. 기존 L/R 이름만 믿어 팔이 교차했던 초안은 폐기했다.
- 화단은 기존 PinkBed 메시/재질을 참조하며 원본을 재생성하지 않는다. 문 통과 경로의 오른쪽에 배치한다. 물방울은 Unity 기본 파티클 모듈만 사용하고, 고정시간 계산으로 배속·일시정지에 맞춘다. 유체·토양 수분·성장·소리는 없다.
- 배낭·목도리·귀는 원래 운반용 상체를 따라오며, 상의–다리 미세 관통 검사는 하지 않는다. 소품 경로/잡는 위치/분사구는 별도 설정이다. 다른 동물 적용은 아직 검증하지 않았다.

## 조작

- 기존 `RabbitHomeLifeStudy`와 `TinyDaysRabbitHomeLife.exe`의 왼쪽 패널에서 **물 주기 검토**를 선택한다. **전체 흐름 · 화단 물 주기**가 이동과 살수를 연결한다. 운반 대기/걷기/물 주기 개별 버튼과각8포즈·두 배속·일시정지·카메라를 제공한다.
- 정지 버튼은 걷기 감속을 요청하거나, 물 주기를 중단하고 약0.5초 동안 물뿌리개를 세운다. 반복 요청으로 재시작하지 않는다. 이미 화단에 도착한 상태의 전체 흐름 재요청은 그 자리에서 다시 물을 준다.
- 출입/물 주기 모드 전환은 명시적 초기화다. 그래프 소유자를 교대하고, 기존 출입 모드는 실내 대기/문 닫힘으로 복구한다. 물 주기 중 출입 자동 왕복은 동작하지 않는다.
- 물 주기 개별 버튼/포즈는 동작 자체 확인용이며 접근 이동 없이 현재 위치에서 재생한다. 화단으로 이동해 물을 주려면 전체 흐름 버튼을 사용한다.

## 검증 현황

- 초안의 감속 경계에서 약11mm/240Hz 위치 변화가 나타났다. 기존 발 제어에 기본값이 꺼진 `SmoothStopBalance`를 추가해 물뿌리개 운반에서만0.15초에 걸쳐 체중 보정을 연결했다. 최신 최대 경계 변화는약5mm/240Hz, 손 속도 최고약2.66→1.27m/s다. 이동 중의 정상 전진도 포함한 수치이며 자동 수치로 품질 승인을 대체하지 않는다.
- 240Hz 전체 흐름의 손 잡기·신발 접지·머리/가슴/양손 위치·속도를 `RabbitWaterMotion240.csv`와 `RabbitWaterVerification.txt`에 남긴다. 두 반복 클립 시작/끝의 관절 위치·회전 일치를 확인했다.
- 30/60/120fps×0.5×/1×, 물 주기8위상 중단/일시정지, 보행 중단4시점, 모드 복원3회 통과. 물방울384개가 화단 흙 범위 안에 도달했다. `RabbitWaterRegression.txt` 참조.
- 최종240Hz: 손 지정 앵커 오차0.293mm·팔 도달 초과0·고정발 이동0.298mm·신발 최저+2.467mm·지지 간격2.580mm. 접촉은 손목 기준점과 손잡이 지정 앵커로 측정하며 손 표면 전체의 충돌을 증명하는 검사는 아니다. 정면/측면/비스듬한 렌더로 양손 실루엣을 별도 확인했다.
- 기존 출입20회 왕복·걷기/달리기96조합 통과. 원본36개 동작 Blender/FBX와 기존3장면 해시 일치(`RabbitWaterPreservation.txt`). 단계별 성공 표식과 종료0은 `Logs/water120-complete.log`에 있다.
- 세 구도12초·1× 영상: `Captures/RabbitWater/Flow90_1x.mp4`(정면), `Flow130_1x.mp4`(비스듬), `Flow180_1x.mp4`(측면). 주요8포즈×3동작×3구도=72장도 보존했다. 연속 프레임 표본에서 들고 걷기/정지/기울이기/살수/복귀를 확인했다. 사용자 무게감·귀여움·부드러움 승인은 별도다.
- Windows 빌드 성공·Data 콘텐츠2026-10-01 21:30:34. 그래픽 활성 상태에서 물 주기 전체 흐름과 기존 출입 자동 실행 모두 종료0(`Logs/water120-player.log`, `water120-home-player.log`). 직접 OS 마우스/키보드 입력 확인은 하지 않았다. **물뿌리개 운반·화단 물 주기 사용자 확인 대기**다.

## 재개·산출물

- 생성: `Tools/build_rabbit_water_art.py`를 Blender5.2.1의 `--background --factory-startup --python-exit-code 1`로 실행한다. `ArtSource/AdultRabbitWater.blend`와 `Assets/Art/Generated/RabbitWater`만 갱신한다. 원래 Motion/Home 소스를 덮어쓰지 않는다.

- 실행 파일은 `Logs/RabbitHomeLifePlayer/TinyDaysRabbitHomeLife.exe`. Git 제외 로컬 산출물이다. 새 생활AI·벤치·농가 적용·GitHub 업로드는 하지 않는다.
