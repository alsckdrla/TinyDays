## 합의·구현

- 4-1 사용자 확인 완료. 기존 캐릭터/정밀 동작·2단계 미완료·2시간 출시 안정성은 그대로 남긴다.
- 봄→여름→가을→겨울, 계절3일. 하루10분 기준30분이며 하루 길이를 바꾸면 진행률을 유지한다. 생활 배속/정지 공유, 조명 시각 고정과 독립. 계절 직접 선택은 시작에 고정하며 자동은 이어간다. Day/시각은 바꾸지 않는다.
- 계절 간10초(시뮬레이션 시간) 재질 전환. 봄 초록/꽃, 여름 짙은 초록, 가을 황금/갈색, 겨울 차분한 식생과 지면·지붕·수관 윗면 눈. 누적 적설/발자국/제설은 미구현이다.
- 겨울에는 날씨의 비 구간을 눈으로 표시하고 같은 처마/자리 예약을 사용한다. 별도의 눈 확률이나 온도는 추가하지 않는다.
- 겨울 작물·열매 성장50%, 휴식 문턱0.1감소·여가1.5배. 기존 성향에 더하며 수확량·식사량은 유지한다. 작업/운반/식사/귀가/심한 피로·식량4개 미만 대응을 유지한다. 성장/작업/자원/예약을 계절 선택으로 초기화하지 않는다.
- 런타임 계절 재질 복사본과 URP 조명/그림자/반투명 대응 셰이더를 사용한다. 원본 메시·수동 자산·이전 장면·창문 재질은 보존한다. 현재 계절과1~3일 진행 표시는 접이식 패널로 제공하며 시간/날씨와 함께 열리지 않는다.
- 저장145에 계절·진행률·고정/자동·전환 시작 가중치/경과를 추가한다. 기존142·144의 생활/날씨/시간/카메라를 검증 후 보존하고 봄/자동만 추가한다. 첫 교체 시 기존 원문을 `.v142`/`.v144`로 남긴다. 기존 파일명은 호환을 위해 유지한다. 실패한 변환은 현재 상태를 변경하지 않으며 자동 저장 차단을 유지한다.
