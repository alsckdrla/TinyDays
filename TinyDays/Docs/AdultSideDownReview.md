- 34 `Adult_Stand_To_Left`: 3.2초/96프레임. 오른발 지지→실제 왼쪽 무릎→오른손 지지→왼쪽 아래팔/팔베개로 내려간다.

- 기존 지지 자세를 제작 참고점으로 사용하지만 복귀 클립을 역재생하지 않는다. 내려가는 경로·접촉 시간·손 떼기는 별도 작성한다. 실제 왼쪽은 legacy `R`, 오른쪽은 `L`이다.
- 기존34개 액션·주머니 없는 메시·가중치·바인드를 보존한다. 작업 전 원본 `Logs/BeforeV0115`, 보존 감사 `AdultSideDownPreservation.txt`.
- 꼬리는 골반 부착 고정, 꼬리 바닥 관통 허용. 배낭/끈은 눕기 검토 규칙을 유지한다. 상의는 약한 흔들림만 적용하며 다리 관통 미세 보완은 하지 않는다.

## 제어

- 왼쪽 패널에 두 직접 눕기 버튼/8포즈를 추가한다. 기존 바로 눕기·돌아눕기·직접 복귀·수면 선택은 보존한다.
- 호흡/변형은 정리를 거치고 이동은 기존 정지·발 모으기를 마친 뒤 진입한다. 진행 중 새 요청은 마지막 것을 예약하며 취소는 현재 전환을 되감지 않는다.
- 완료하면 눈을 뜬 옆누운 자동 호흡. 호흡 위상은 유지하며 접촉 중에는 가슴의 가동 여유에 맞춰 호흡 변형 강도만 완만하게 줄인다. 끝에서 기존 옆누운 호흡에 합류한다.
- 몸동작 타이밍과 성인 토끼의 지지 위치를 분리한다. 다른 동물의 실제 호환은 미검증이다.

## 발견한 문제와 보완

- 초안에서 손이 떠 있고 왼쪽 종아리 회전이 약15도/240Hz까지 증가했다. 정규화한 무릎 굽힘 방향과 축 회전 보존, 무릎의 지정 지지 구간, 몸 이동과 손 경로를 조정했다.
- Unity 검사에서 손 떼기 직후 약2mm 바닥 관통을 발견했다. 원본과 실행을 분리 측정해 호흡만의 문제가 아님을 확인했다. 새 두 클립에만 선형 가져오기 접선을 적용하고 손을 먼저 들어 올린 뒤 회수하도록 별도 경로를 작성했다. 기존34개 클립의 가져오기 접선은 변경하지 않는다.
- 첫 Unity 영상에서는 손 지지 교대 중 가슴이 다시 세워지며 머리가 크게 올라왔다. 중간 제어점 범위를 넘지 않는 보간, 가슴의 옆 기울기와 팔꿈치 방향/도달 여유를 조정했다. 최종 실행의 짧은 머리 재상승은 서기14.253mm·앉기1.764mm이며 완전한 단조 하강이라고 주장하지 않는다. 특히 서기 중 지지 교대의 느낌은 사용자 품질 확인 대상이다.
- 초안 실패 수치는 최종 통과를 뜻하지 않는다. 최종 지지/회전/끝 자세 결과는 `AdultSideDownVerification.txt`, 240Hz 기록은 `AdultSideDownMotion.csv`에 남긴다.
