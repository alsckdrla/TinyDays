최종 갱신: 2026-10-02. **동그란 눈 사용자 확인 대기**.

## 후속 크기 조정 — 현재 파일 기준

- 사용자 요청에 따라 원형 눈 가로/세로를 각각10% 축소했다(102→91.8mm). 중심·간격·깊이·얼굴 비율은 유지했다. 하이라이트의 크기/상대 위치도90%로 맞춰 표면에 재투영하고 눈 감기에도 같은 축소를 적용했다.
- 축소 전 백업은 `ArtSource/Backups/AdultRabbit - 01.before-eye-shrink-20261002.blend`. 자동 보존 검사 통과, 정면/측면/비스듬×0/50/100% 눈 감기 전후18장은 `Captures/UserRabbitEyeShrink`, 검사 결과는 `UserRabbitEyeShrinkVerification.json`. 아래102mm 기록은 축소 전 단계다.
- 현재 **10% 축소한 동그란 눈 사용자 확인 대기**. Blender 파일만 반영했으며 FBX/실행 프로그램/GitHub는 변경하지 않았다. 도구는 기존 두 스크립트에 `-- --shrink`를 전달하며 기존 백업을 덮어쓰지 않는다.

- 대상은 `ArtSource/AdultRabbit - 01.blend`만이다. 사용자가 수정한 아래쪽이 조금 납작한 얼굴 비율을 그대로 보존했다. 이 파일에는 골격과 `Basis`/`SleepEyesClosed`가 있으며 애니메이션 액션은 없다.
- 눈 로컬 높이 약102mm를 유지하고 가로 폭77.994mm→102mm로 확대했다. 좌우 확대 비율은 약1.30779배다. 중심과 표면 방향, 눈의 깊이 축과 세로 좌표는 유지했다. 가로·세로 폭 기준으로 원형 실루엣을 맞췄으며 로우폴리 면수는 그대로다.
- 기존25정점 흰 하이라이트는 가로·세로 크기와 눈에 대한 위치를 유지하고 확대된 눈 삼각면에 재투영했다. 기존 약0.5mm 표면 간격을 유지했다. `SleepEyesClosed`의 눈 가로 폭도 같은 기준으로 늘리고 하이라이트의 안쪽 숨김 변위를 유지했다.
- 수정 전 백업: `ArtSource/Backups/AdultRabbit - 01.before-round-eyes-20261002.blend`. 수정 도구는 `Tools/round_user_rabbit_eyes.py`이며 백업이 이미 있으면 덮어쓰지 않고 중단한다. 다른 모델 생성 도구를 실행하지 않는다.
- 자동 보존 비교: 눈74정점×2와 하이라이트25정점×2 이외의 메시/두 셰이프키 정점 동일. 전체 토폴로지·재질 배정·가중치·골격 바인드·오브젝트 변환 동일. 새 정점/재질0. `UserRabbitRoundEyesVerification.json` 참조.
- `Tools/render_user_rabbit_eyes.py`는 파일을 읽어 임시 카메라로 렌더만 하며 소스를 저장하지 않는다. 정면/비스듬/측면의 눈 감김0/50/100% 전후18장을 `Captures/UserRabbitRoundEyes`에 저장했다. 렌더에서 원형 눈·하이라이트 밀착·눈 감기 및 하이라이트 숨김을 확인했다. Blender UI의 실제 입력 확인과 사용자 외형 승인은 별도 미확인이다.
- 생성 모델·FBX·애니메이션·Unity 장면·Windows 검토 프로그램에는 반영하지 않았다. 기존 실행 프로그램은 v0.122 모델을 계속 사용한다. GitHub 미업로드. 다음은 새 눈 외형 확인이며 기존 모션 자산에 새 얼굴을 연결하려면 별도 요청으로 진행한다. 벤치 및 기존 동작의 사용자 승인 상태는 바꾸지 않는다.
