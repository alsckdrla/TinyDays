- 3-5 사용자 확인 완료. 기존 캐릭터 외형·정밀 동작과 2단계 미완료 사항은 보류 그대로 유지한다.

- 처마와 비는 자율 생활 장면의 런타임 생성 표현이다. 기존 집·원본 모델·장면 파일은 재생성하지 않았다. 신규 정밀 동작·물웅덩이·소리·계절·무작위 날씨는 포함하지 않는다.
- 새 저장은 envelope 144. 기존 142를 검증한 뒤 기존 생활·시간·구도를 유지하면서 맑음/자동을 추가한다. 첫 정상 교체 시 `.v142`에 이전 원문을 보존한다. 파일명 `AutonomousLife142.json`은 기존 저장을 계속 찾도록 유지한다. 변환 실패 시 현재 상태/원본을 보존하고 자동 저장을 차단한다.
