- 자동: 농가 재생성·수동 영역 보존과 기존 회귀 검사, 네 시간 선택, 원본 재질 보존 통과. `Stage27LightingVerification.txt` 참조.
- 정지 렌더: `Captures/Stage27Lighting`의 네 시간대 전체/근접 동일 구도 이미지 확인. 푸른 밤·따뜻한 창문, 서로 반대 방향의 일출/일몰 그림자 확인.
- 실제 Windows 1280×800: 시간 패널 열기와 밤 선택, 주민 이동 지속 및 카메라 구도 유지 확인. 최초 빌드에서 창문 발광 셰이더 변형 누락을 발견해 생성 재질의 발광 변형을 포함하도록 수정.

- 수정 후 독립 실행 파일 재검증: 1280×800에서 밤 창문 발광 표시를 확인했다. 일출·일몰 전환과 선택 표시, 주민 이동 지속·카메라 구도 유지도 직접 확인했다. 일몰의 상단 안내 글씨 대비는 후속 UI 가독성 검토 대상으로 남긴다.
- 사용자 대표 조명 승인 대기. 캐릭터 관련 보류 작업의 완료를 의미하지 않는다.

## v0.42 색감·창문 불빛 보완 (2026-09-16)

- 수정 전 8개 비교 이미지는 `Captures/Stage27Lighting/Before-v042`에 보존했다. 같은 전체/근접 구도로 다시 렌더해 일출의 붉은빛·차가운 그림자, 일몰의 오렌지빛, 같은 집 안의 연녹색·따뜻한 색 및 창고의 푸른 창문을 확인했다.
- Windows 검토 빌드 생성 통과. 갱신한 독립 게임 창 1280×800에서 시간 패널을 열고 일출→일몰→밤을 직접 클릭했다. 선택 표시·조명 변화·창문별 색 차이·주민 이동 지속을 확인했다. 낮 시작 화면은 창문 발광이 꺼져 있었다.
- 자동: 창문 분리·집 안의 색 다양성·재생성 전후 동일 색 배치·낮 발광 해제·반투명 복원 후 색·원본 재질 및 수동 영역 보존 통과 (`lighting-v042-final.log`: `STAGE27_LIGHTING_OK`). 별도 `Stage27LightingVerification.txt` 참조. 기존 카메라 비교 PNG 파일 잠금으로 추가 검사가 중단되어, 해당 중복 렌더만 생략하고 모든 회귀 검사와 이번 조명 비교 렌더를 재실행해 통과했다.
- 일출·일몰의 상단 안내 글씨 대비는 후속 UI 가독성 검토 대상으로 남긴다. Editor Play 및 다른 창 크기의 종합 검증은 이번 실제 입력 확인에 포함하지 않았다.
- **2-7-1 사용자 재확인 대기**. 자동 순환과 5분 관찰은 아직 진행하지 않았다.
