# 자율 생활 첫 흐름 v0.139

2026-10-05. 3-1·3-2 첫 검토판. 최종 외형/애니메이션 승인이나 2-7-3 완료가 아니다.

## 합의와 현재 구성

- 성인 토끼3명, 이미 정착한 농가, 야생 열매3곳/당근6작업자리, 창고3자리/쉼터3자리/주민별 귀가 지점. 이 수량은 검토 구성이다.
- 낮에는 필요에 따라 채집·심기·수확·운반·식사·휴식·감상을 선택한다. 기본 하루10분·Day1 12시,20시 귀가·6시 활동 재개. 배속/일시정지/시간대 비교/카메라는 기존 농가 검토 조작을 사용한다.
- 집/창고/지형은 기존 농가의 별도 복사 장면이며 구형 주민 대신 현재 성인 토끼 파생 FBX를 사용한다. 원본 Blender·FBX·기존 장면을 수정하지 않았다.
- 캐릭터 세부 품질 보완은 보류한다. 농사/식사/휴식은 우선 작업 위치에서 기존 대기 동작을 사용하며 작물 크기·열매 유무·운반 바구니·창고 재고와 선택 주민의 행동/이유로 결과를 읽게 한다. 귀가는 집 앞 접근 지점 도착 후 외부 모델을 숨기는 임시 실내 표현이다. 세밀한 문 통과/실내 수면/벤치 착석은 이 자율 장면에 연결하지 않았다.
- 첫 장면은 진행 저장이 없다. 새로 실행/처음부터는 초기 상태로 돌아온다. 저장은3-4에서 별도 합의한다. 건설·확장과 새 주민 종은 추가하지 않았다.

## 구현과 검토값

- AutonomousSimulation: 생활/생산/예약/물품 소유. AutonomousNavigation: 장면 지표 범위에서 장애물 여유를 반영하는 격자 경로와 주민 양보. AutonomousLifeWorld: 공통 시계와 표시 연결. 기존 FarmLifeDirector는 고정 경로 재생을 끄고 카메라/검토 조작의 어댑터로만 사용한다.
- 초기 식량9, 용량36, 생산 목표18. 당근 생산3/성장80초, 열매2/회복100초. 작업5초·식사4초·휴식12초·여가10초. 검토 속도이며 최종 밸런스가 아니다. LifeTuning에서 변경 가능하다.
- 주민별 초기 배고픔/피로·휴식 문턱·채집 선호를 조금씩 다르게 두되 모두 같은 일을 수행할 수 있다. 식량이 부족하면 생산을 우선하며, 재고가 넉넉하면 여가를 선택한다. 사망/붕괴는 없다.
- 작업 자리는 단일 소유자, 운반 중 음식은 주민 소유다. 실패하면 자리를 해제하고 음식은 회수 가능한 묶음으로 남긴다. 보관량·운반량·바닥 묶음·소비량의 합으로 중복/손실을 검사한다. 바닥 묶음은 현재 논리 상태이며 별도 떨어진 바구니 외형은 후속 보완 대상이다.
- 야간에 운반과 진행 중 작업을 정리하고 귀가한다. 막힌 귀갓길은 안전한 현재 위치에서 쉬며 재시도한다. 길이나 목표가 막히면 해당 후보를 잠깐 보류하고 다른 행동을 찾는다.
