# 보행·내려놓기·벤치 접근 — v0.131

갱신: 2026-10-03. **구현·자동 검사·빌드/실제 버튼 확인 완료 / 사용자 동작 품질 확인 대기.**

## v0.131 합의와 구현

- 원본 모델·FBX·클립·수동 장면은 재생성하지 않는다. 같은 위상의 원본 다리 길이와 자세를 기준으로 착지점을 계획하고, 고정된 지지발을 끌거나 다리를 늘리지 않는다.
- 공중 발의 도달 보정이 다음 고정 착지점을 덮어쓰던 처리와 출발→보행의 첫 접촉 인계를 보완했다. 작은 수평 무게중심 보정과 연속 높이 보정을 함께 사용한다.
- 추가 골반 하강 1cm·지지 무릎 추가 굽힘 10도·240Hz 높이 보정량 변화 2mm 기준을 유지한다. 출발·착지·대기로의 회복 시간은 연결에 맞춰 조정했으며 본게임 확정 밸런스가 아니다.
- 내려놓기 방식은 이번 사용자 계획으로 확정됐다. 1.05초까지 현재 잡은 방향으로 바닥에 놓고, 1.35초까지 손을 뗀 다음 1.8초까지 바닥 위 소품만 보관 방향으로 정리한다. 손 분리 후 소품 회전은 팔에 전달하지 않는다.
- 벤치 이탈은 현재 신발 정점·물뿌리개 범위와 짧은 발 들기 구간, 벤치·벽/소품 경계를 검사한다. 낮은 뒤걸음을 작은 구간으로 연결하고, 마지막 접근은 벤치와 평행한 짧은 직선 구간으로 정리하고, 벤치 앞 여유를 확보한 뒤 짧은 뒤걸음으로 착석 위치에 들어간다. 막힌 경로는 현재 위치에서 대기한다.
- 중단 후 이탈이 덜 끝났으면 남은 안전 이탈을 먼저 이어간다. 기존 문 자동 닫힘과 UI/배속/초기화는 유지한다.

벤치 접근은 실제 신발 범위의 여유를 확보한 검토 위치다. 마지막 접근을 벤치와 평행한 구간으로 정리하고, 이탈/착석 준비의 긴 이동은 짧은 발 디딤으로 나눴다. 막힌 경로는 관통하지 않으며, 전체 마을용 범용 경로 탐색기 완료로 취급하지 않는다. 원래 벤치 좌판·휴식 발 높이·앉기/일어서기 클립과 집/소품/보관 위치는 유지했다.

일부 중간 실험은 실패했다. 단순 높이 보간·양방향 수평 투영, 긴 이탈, 짧은 경로의 과도한 끝 회전, 경유점의 추가 회전 안은 제거했다. 한 통합 로그는 다른 검사까지 통과한 뒤 낡은 테스트 가정/단독 벤치에서 실패했다. 최종 항목별 로그를 사용하며 실패 로그를 전체 성공 근거로 삼지 않는다. 기존 '0.12초 뒤 단계가 그대로' 가정은 실제 진행 중 단계/위치 보존으로, '6초 내 모든 요청 완료'는 유한 완료와 엄격한 접지 검사로 수정했다. 물리 기준은 완화하지 않았다.

- 같은 구도의15fps·1× 전체 생활 렌더다. 처리 타이밍이 달라 영상 길이는 다르다. 현재 평가된 스킨 정점을 렌더해 GPU 이전 포즈 캐시를 피했다. 대표 프레임을 확인했으며 영상/정지 렌더는 실제 OS 입력이나 사용자 품질 승인을 대신하지 않는다.

- 초기 Windows 화면 캡처가 다른 창을 보여준 표본은 게임 표시 근거에서 제외했다. 게임 창을 활성화한 뒤 정상 창을 다시 확인했다.

## 원인과 구현 초안

- 사용자 영상: `Docs/Check/Tiny Days HomeLife Walking chk 2026-10-03 15-10-07.mp4`. 접근과 돌아서는 구간에서 큰 웅크림을 확인했다.
- 기존 생활 IK가 대기/이전 보정 단계에서 읽은 다리 길이를 계속 사용했다. 원본은 회전 외에 관절 위치도 위상별로 애니메이션하므로 현재 샘플의 길이를 보존하도록 변경했다. 기본 모델·클립·FBX를 다시 만들지 않는다.
- 거리 기반 걷기 위상을 유지하고 남은 디딤 거리로 미래 위치를 계산한다. 경로의 접선과 실제 몸 회전의 차이를 고려해 착지 방향을 예측한다. 공중 발의 도달 때문에 몸 전체를 낮추지 않도록 분리했다.
- 지지발 접지를 유지하면서 골반 높이/무릎 굽힘을 맞추는 초안은 아직 착지 때 높이가 바뀐다. 추가 관절 늘림으로 해결하지 않는다. `FollowWalkingHeading`을 사용하는 생활 보행에 한정했다.
- 현재 위치 주변 접근 후보를 선택하고 집/화단의 정적 메시 삼각형 경계 및 보관 소품 여유를 검사한다. 원래 보관 자세와 이번 접근 자세는 분리했다. 집기 준비 중 소품은 중심을 유지한 채 바닥 수직축으로 회전한다.

## 자동 검사와 남은 실패

- 이전 진단 최대 추가 골반 하강359.8mm. `Logs/natural129-walk11.log`의 중간 초안은 약8mm 하강, 추가 지지 무릎 굽힘 약10.213도다. 전체 흐름 완료 로그는 자세 검사 PASS와 다르다.
- 같은 진단의 240Hz 표본에서 착지 경계의 실제 골반 높이 변화 약28.5mm가 남았다. 자연스러운 보행으로 승인할 수 없다. 골반 수평 정렬을 추가한 다음 실험(walk12)은 악화되어 제거했다.
- `natural129-posture3.log` 단계에서160개 일반/운반 회전 및8개 중단/재개가 통과했지만 이후 착지 예측을 변경했다. 최신 코드 전체 재검사가 필요하다.
- `natural129-draft3.log`: 내려놓기 반대 방향180도에서 도달 초과 약35mm. 추가 상체 숙임으로 가리려던 실험은 제거했다. 따라서 이 로그의 일부 방향 성공도 현재 코드의 최종 검증으로 사용하지 않는다.
- `natural129-flow1.log`: 새 보관점 접근 후 벤치 출발 약0.196초에 Shoes와 보관 소품이 겹친다. `RabbitBenchReview.StartConnectedFlow`의 이탈 계산은 기존 고정 접근을 가정했으므로 새 접근 전체를 지원해야 한다.
- `RabbitNaturalWalkChecks.Diagnose`는 진단 기록 함수이며 통과 판정 함수가 아니다. 현재 CSV는 마지막 실험 결과일 수 있으므로 로그 이름/코드 상태를 함께 확인한다. `Pickup`/`Draft`는 미완료 테스트다.

## 사용자 결정이 필요한 항목
