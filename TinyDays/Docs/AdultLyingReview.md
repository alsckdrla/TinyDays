서기↔앉기 부분은 기존 한 손 지지 동작을 보존한 채 새 클립에서 샘플링한다. 이를 새 상체 눕히기/들기 경로와 관절 단위로 겹친다. 복귀는 별도의 머리·상체·손 지지/회수 곡선과 일어서기 원본을 사용한다. 동일 하강 클립의 역재생이 아니다. 120Hz 원본 키와 FBX 베이크, Unity240Hz 측정.

손을 배 위에 두고 기존 꼬리 관절을 옆으로 비켜 놓는다. 머리·몸·손·다리는 원래 길이를 유지한다. 귀·목도리는 약한 후행, 상의는 약한 절차적 살랑거림만 사용한다. 상의–다리 미세 관통 보완은 하지 않는다. 원본 모델이나 농가를 바꾸지 않는다.

## 검토 제어

왼쪽 패널의 **서기 → 눕기 / 앉기 → 눕기 / 누움 → 서기 / 누움 → 앉기**를 사용한다. 해당 자세에서 가능한 전환만 활성화한다. 8포즈·0.5×/1×·일시정지·기존 카메라 사용. 다른 동작 선택은 눕기 검토를 종료하는 명시적 초기화다.

호흡/변형은 기존 정리 후, 이동은 정지·발 모으기 후 눕는다. 누운 중 걷기/달리기 요청은 눕기→서기 후 연결한다. 전환 중 마지막 이동 요청이 우선하며 취소해도 진행 중 전환은 끝낸다. 배낭+끈 렌더러를 함께 숨기고 검토 종료/다른 클립/초기화/비활성화 때 이전 상태로 복구한다.

## 검증 구분

- `AdultLyingChecks.Execute`: 240Hz 손/신발/머리 바닥 검사, 팔다리 길이, 명시한 손바닥 고정 구간, 공통 끝 자세, 30/60/120fps와0.5/1× 상태 연결·취소·반복·배낭 복원. 몸이 순차적으로 굴러 닿거나 다리를 정리하는 동안의 접촉점은 고정 지지점과 구분한다.
- 팔꿈치 지지의 무게감과 순차적 등/골반 접촉은 렌더 확인 대상이다. 손바닥 측정 통과를 모든 피부 접촉점의 검증으로 확대하지 않는다. 물리 기반 지지력 검사가 아니다.

- 보존: `Logs/BeforeV0106/AdultRabbitMotion.blend`, `verify_sitting_preservation.py --v0106`, `AdultLyingPreservation.txt`.
