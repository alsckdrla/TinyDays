## 종료·새 프로세스 복원과 최종 확인

- 정상 종료 시 저장 파일 payload가 Expected143와 정확히 같았다. 최종 life143-final-build.log의 LIFE140_PLAYER_OK·종료0. 복원 후 활동 판정만 생산 증가에서 활동 완료 증가로 변경했으며 정상 생활/저장 코드는 바꾸지 않았다.
- life143-resume.log의 LIFE143_RESTART_EXACT_OK: 새 프로세스의 행동·진행량·위치·식량·예약·시계·정지/카메라 전체 JSON 일치. 이어60.4초 생활에서 활동 완료가 증가해 LIFE143_RESUMED_LIFE_60SEC_OK를 통과했다. 검증 끝에서만 정지해 정확한 종료/복원 비교를 수행하며30분 중간에 멈추지 않았다.
- 최종1280×800 창에서 Esc 저장 UI/잘림을 확인하고, 설정창 중 Home 입력 후 저장한 카메라 정보가 전후 정확히 같은 것을 확인했다. 실제 입력 검사와 프로그램 상태 검증을 구분한다.
