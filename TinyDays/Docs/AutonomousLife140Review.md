# 3-3 부족·혼잡·개인차 v0.140

2026-10-05. 3-2 전체 흐름 사용자 확인 후3-3을 진행한다. 기존2단계 미완료와 캐릭터 세부 품질 보완 보류는 유지한다.

## 구현 기준

- 주민1 농사 선호,2 채집 선호,3 느긋함. 모두 모든 일을 할 수 있다. 농사 선호는 수확/심기, 채집 선호는 열매를 먼저 선택한다. 느긋함은 휴식 문턱0.1 감소·여가1.5배(15초)의 임시값이다. 성향을 끈 비교 조건은 Balanced다.
- 운반 정리/배고픔/밤 귀가/심한 피로를 취향보다 먼저 처리한다. 식량4 미만이면 성향보다 즉시 얻을 수 있는 수확물·열매가 우선이다. 생산 목표18·용량36·초기 식량9·하루10분은 기존 검토값이다.
- 예정 재고는 창고+운반+수확/채집 예약+바닥 물품 회수 예약이다. 작업을 배정할 때 전체 수확량이 들어갈 여유를 확보한다. 식사 예약은 창고 식량의 일부이며 별도 물품으로 중복 계산하지 않는다. 소비는 식사 완료 때만 발생한다.
- 같은 필요는 기다린 시각 순으로 작업 기회를 얻는다. 다른 자리 사용/안전 대기 장소/재시도를 연결한다. 좁은 길은 잠시 기다린 뒤 우회하고 계속 막히면 작업을 해제한다. 통행 양보는 운반 중·오래 기다린 주민 우선이며 기존 거리 기준을 줄이지 않는다.
- 이동 중인 주민이 목적지를 점유한 경우 접근 경로를 계획할 수 있게 하고 실제 이동의 충돌 검사를 유지한다. 고정 장애물은 통과하지 않는다. 서로의 출발점을 목적지로 삼는 교환 배치가 최초 검사에서 멈추던 문제를 이 기준으로 보완했다.
- 중단된 운반은 현재의 안전한 위치에 물품 ID/수량/소유자를 가진 묶음을 남기고 바구니로 표시한다. 재회수는8초 후부터 재시도해 계속 집었다 놓는 반복을 줄인다. 회수·초기화 때 표시도 제거한다.
- 나무 옆·밭 가장자리 감상3곳과 대기3곳을 기존 장면에 추가한다. 새 식물/작물 장애물까지 구성한 뒤 모든 자리의 안전 위치를 확인한다. 정밀 동작 없이 기존 대기/걷기와 소품 표시를 사용한다.
- 기존 주민 안내에 성향/행동/이유를 두 줄로 표시하고 상단 안내·시간 패널 위치를 함께 맞춘다. 기존 농가 장면의 UI 배치는 바꾸지 않는다.
