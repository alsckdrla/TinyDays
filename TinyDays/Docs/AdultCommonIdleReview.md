# 공통 기본 호흡과 이동 연결 — v0.93

갱신: 2026-09-24. **앉기·서기 기본 호흡과 이동 연결 사용자 확인 대기**. v0.92 최종 품질 승인은 추정하지 않는다.

## 범위와 사용

- 기존 인덱스 0~7 유지, 8 `Adult_Breathe_Stand`, 9 `Adult_Breathe_Sit` 추가. 각각 120프레임/4초다. 기존 앉은 정지 기준은 7로 보존한다.
- 검토 화면의 `서기 기본 호흡` / `앉기 기본 호흡`은 독립 동작 선택이다. 해당 상태에서 걷기/달리기를 누르면 정리·필요한 일어서기를 거쳐 현재 위치에서 출발한다. `이동 검토 / 처음 위치`만 명시적인 위치 초기화다.
- 자동 변형 토글은 준비되어 있지만 추가 변형은 아직 0개다. 이번에는 호흡 이외의 동작을 무작위로 만들어 재생하지 않는다.
- 공통 제어 `CommonIdleDirector`는 동물 이름을 사용하지 않는다. 동일 골격 몸 클립과 전환/기준 클립을 주입하며, `IdleSecondaryMotion`에 선택적 관절·축·강도·후행을 설정한다. 토끼 부위 연결은 검토 장면 생성기의 프로필에 한정한다.
- 새 호흡 생성은 `Tools/adult_common_breathing.py`, 기존 생성기에서 호출한다. 앉기/서기 상의는 1.5mm 수준의 단순 밑단 흔들림이며 다리 표면 추적은 하지 않는다.

## 자동 검사 — 현재 결과

- Blender 작업 전 `Logs/BeforeV093/AdultRabbitMotion.blend` 대비 **기존 8개 액션 F-curve·메시·바인드 골격 해시 10항목 일치**. `verify_sitting_preservation.py --idle` 사용.
- 240Hz: 앉기/서기 가슴 상하 폭 각각 **7.000mm**, 골반/양발 관절 이동 0.0000mm, 반복 끝 자세 차이 0.0000mm. 목 길이 변화 각각 0.0001/0.0003mm 수준. 시간에 따른 스케일 변화 없음. 서기 양쪽 신발 바닥 +2.500mm, 앉기 양쪽 +4.500mm.
- 앉기/서기 × 8위상 × 걷기/달리기 × 30/60/120fps × 0.5×/1× = **192개 출발 조합 통과**. 위치 초기화 없이 프레임의 남은 출발 시간을 소비한다(출발로 넘어간 관측 프레임의 정상 전진 최대 0.355mm). 마지막 요청 적용·반복 요청·일시정지·정리 중 취소·일어서기 중 취소·빈 후보·클립 초기화 확인.
- 초기 검사에서 기존 서기 기준의 오른발이 떠 있는 점과 로컬 관절 보간 중 접지 이탈을 확인했다. 기존 8개 클립은 그대로 두고 새 서기 호흡만 양발 +2.5mm 접지 자세로 생성했다. 정리 끝을 실제 기존 이동 제어의 출발 자세로 연결하며, 공통 프로필의 다리 관절 참조로 짧은 정리 구간만 접지를 유지한다. 골격·메시·정상 이동 제어는 변경하지 않았다.
- 수정 후 정리 지지발 이동 최대 **0.053mm**, 검사한 전체 새 연결의 신발 최저 **+1.002mm**. 240Hz 전체 렌더러 정점의 최대 프레임 이동은 7.316mm이며 일어서기 동작도 포함한다. 이 수치를 머리 떨림이나 사용자 품질 승인으로 해석하지 않는다.
- 테스트 전용 두 후보로 고정 시드 재현·연속 동일 후보 제외를 확인했다. 배포 후보는 여전히 0개다. 발을 드는 미래 후보는 회복 궤적과 실제 접촉 판정 어댑터 없이 등록되지 않도록 제한한다.
- Blender 원본을 다시 여는 검사에서 새 액션 보존 설정 누락을 발견해 수정했다. 원본에 두 호흡 액션이 실제 남는 것을 확인했고, `measure_common_idle.py`가 이를 열어 240Hz 곡선을 측정한다.
- 기본 자동 핸들의 반복 경계 감속은 주기형 연속 스플라인으로 교체했다. 원본 가슴 최대 가속도는 서기 약 0.481→0.014m/s², 앉기 0.482→0.009m/s², 머리는 0.627→0.022 / 0.611→0.016m/s²다. 최종 반복 위치 차이 0, 속도 경계 차이 최대 약 0.0000144m/s. 원본 수치이며 Unity의 선형 베이크/실제 화면 품질과 구분한다. 근거 `AdultCommonIdleCurves.json`.
- 프레임률/배속별 출발 시각, 포즈 정지 후 이동, 비활성화 정리와 명시적 재시작도 통과했다. 모두 직접 함수/클립 호출이며 실제 Game 입력이나 사용자 자연스러움 승인이 아니다.

## 후속 제작과 제한

1. 기본 호흡/이동 연결 사용자 확인.
2. 앉아서 크게 내쉬기 / 서서 가슴을 들며 큰 호흡.
3. 앉아서 좌우 발목 번갈아 까딱 / 서서 좌우 체중 이동.
4. 앉아서 두리번거리며 바닥 긁기 / 서서 아래 보며 뒤꿈치 톡톡.
5. 손가락 추가 없이 두 손을 맞대 앞으로 미는 스트레칭.

향후 추가 클립은 기본 자세와 연결되는 시작/끝, 발이 떠 있을 때의 회복 궤적·실제 접촉 검증을 포함해야 한다. 아직 만든 적 없는 변형의 발 내리기 품질을 이번 호흡 검사만으로 보장하지 않는다. 다른 동물의 실제 체형/관절 길이/접지 호환은 미검증이다. 농가·눕기·GitHub 업로드 제외.
