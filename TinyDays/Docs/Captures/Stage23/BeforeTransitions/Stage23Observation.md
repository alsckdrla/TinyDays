# 2-3 첫 검토 — 기본 이동 관찰 기록

날짜: 2026-09-14. 상태: **기본 이동 사용자 확인 대기**.

## 제작 범위

현재 승인 외형에서 대기 2종·두 발 걷기·낮은 깡충 이동을 만들었다. 기존 외형 원본과 장면을 보존했다. 자세 전환·시작/정지 연결·특별 행동은 사용자 기본 이동 확인 후 제작한다. 검토 버튼으로 다른 자세를 고르면 즉시 바뀌는 것은 클립 선택 도구의 동작이며 자세 전환 연출이 아니다.

## 자동 검사와 비교 이미지

- Blender 5.2.1 / Unity 2022.3.20f1 / URP 14.0.10 / Generic.
- 4개 클립에서 관절 위치·표면 크기의 가져오기 차이, 반복 경계, 지면 관통 범위를 검사했다. 결과는 [자동 검사](Stage23Verification.txt)에 있다.
- [접지 궤적 검사](Stage23ContactVerification.txt)는 지지 관절 이동과 Unity 전진량을 합쳐 검사한다. 실제 발 표면이나 접촉의 자연스러움 전체를 보증하는 수치가 아니다.
- 정면·측면·후면·비스듬한 구도에서 네 시점과 축소 구도를 촬영했다. 동기식 배치에서 실시간 스키닝 갱신 없이 잘못된 정지 자세가 찍히는 문제를 발견했다. 가져온 관절 행렬로 평가한 표면을 임시 메시로 촬영하도록 수정했다. 이 이미지는 가져온 자세의 비교 자료이며 실제 Game 창 관찰과 별개다.
- 재생성 두 번의 ManualEdits 시험 개체 보존 확인, 원본 RabbitStudy.blend/FBX/장면 해시 일치, 프로토타입 Git 차이 해시 일치를 확인했다.

## 실제 Unity Game 창

실제 편집기 RabbitMotionStudy의 Game 창, QHD 2560×1440 설정·표시 배율 약 0.86에서 Play 모드에 진입했다. 별도의 테스트 창이나 자동 함수 호출을 실제 입력 확인의 근거로 사용하지 않았다.

- 최신 얼굴·복장과 두 발/네 발 외형이 Play 모드에 표시된다.
- 네 가지 동작을 버튼으로 선택하고 실제 자세·동작·표시 이름이 바뀌는 것을 확인했다.
- 두 발 걷기와 깡충 이동은 전진하며 카메라가 따라간다. 바닥 표시를 통해 전진이 구별된다.
- 일시정지에서 시간이 고정되고, 처음부터 누르면 0.00초 및 시작 위치로 돌아간다. 재생을 누르면 이어서 진행한다.
- 느린 재생 전환, 가까운/축소 크기, 정면·측면·후면·비스듬한 고정 구도 선택을 확인했다. 검토 도구의 조작이며 본게임 카메라나 배속 구현이 아니다.
- 최초 GUILayout 버튼 입력이 실제 Game 창에서 반응하지 않는 문제를 발견해 화면 좌표 입력으로 수정했다. 수정 후 실제 창에서 버튼 선택·정지·재개·초기화가 반응하는 것을 확인했다.
- 마지막으로 검토 바닥을 접지 기준 높이에 맞추고 가까운 구도에서 귀가 상단 검토 UI와 겹치지 않도록 여백을 조정했다. 자동 검사를 다시 통과했고 실제 Game 창에서 걷기·깡충 이동을 재확인했다.

## 남은 확인

사용자가 걷기의 편안함, 낮은 깡충 이동의 토끼다운 느낌, 반복과 발 접촉의 자연스러움을 확인해야 한다. 사용자 확인 없이 첫 검토 통과나 2-3 완료를 기록하지 않는다. 연결 동작, 다른 종, 종합 농가 5분 관찰, 출시 장시간 안정성과 성능 검증은 아직 수행하지 않았다.
