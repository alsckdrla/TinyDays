# 2-3 두 번째 검토 — 자세 전환·이동 연결 관찰 기록

날짜: 2026-09-15. 상태: **기본 이동 사용자 확인 완료 / 자세 전환 사용자 확인 대기**.

## 제작 범위

승인한 외형과 기본 4동작을 유지하고 두 발↔네 발 전환, 걷기·깡충 이동의 출발/정지 6클립을 추가했다. 내려가기 1.2초, 일어서기 1.4초, 출발·정지 각 0.6초는 검토용 값이다. 빈손 토끼 한 명의 연출 장면이며 자율 판단·신남·호기심·소품 연출은 이번 범위에 없다.

연결 장면은 약 16.4초 동안 한 번 진행하고 마지막 두 발 대기를 유지한다. 개별 동작 선택은 시작 위치와 자세를 초기화한다. 단발 전환·정지 후에는 해당 대기, 출발 후에는 해당 반복 이동으로 이어진다. 실제 위치는 Unity의 누적 이동량으로 제어한다.

## 자동 검사와 비교 자료

- Blender 5.2.1 / Unity 2022.3.20f1 / URP 14.0.10 / Generic을 유지했다.
- [Unity 자동 검사](Stage23Verification.txt): 10클립 길이, 관절·표면 크기 가져오기, 반복 경계, 연결 표면의 끝/처음, 단발 후속 처리, 누적 이동·마지막 대기·재시작과 수동 영역 보존 통과.
- [접지 궤적 검사](Stage23ContactVerification.txt): 지지 관절과 Unity 누적 전진을 합친 궤적 검사 및 기존 기본 4동작의 이전 자료 대조 통과. 발 표면 전체의 시각적 미끄러짐이나 자연스러움에 대한 사용자 승인을 대신하지 않는다.
- 양방향 전환과 네 출발·정지 클립을 정면·측면·후면·비스듬한 방향의 다섯 시점과 축소 구도로 촬영했다. [비교 이미지](Captures/Stage23/Unity/)는 가져온 관절 행렬로 표면을 평가한 동기식 배치 자료다. 실제 Game 창에서는 원래 SkinnedMeshRenderer와 Generic Playable을 사용한다.
- [수정 전 자료](Captures/Stage23/BeforeTransitions/)에 기본 이동 비교 이미지·관찰 기록·자동 검사·접지 검사·원본 audit를 보존했다.
- 재생성 두 번의 ManualEdits 시험 개체 보존 검사를 통과했다. 승인 외형 원본 RabbitStudy.blend·FBX·정지 장면의 SHA-256 및 프로토타입 Git 차이 해시가 작업 전후 동일하다.

## 실제 Unity Game 창 확인

실제 RabbitMotionStudy Game 창에서 Play 모드에 진입했다. QHD 2560×1440 설정, 표시 배율 약 0.86이며 이번에는 다른 창 비율이나 Windows 실행 파일을 검사하지 않았다. 자동 함수 호출이나 배치 이미지를 실제 입력 확인으로 기록하지 않았다.

- 정상 1× 연결 재생에서 네 발 대기로 이어지고, 완료 후 두 발 대기를 유지하는 화면을 확인했다.
- 느린 0.5× 재생을 선택하고 두 발→네 발 개별 동작이 네 발 대기로 이어지는 것을 확인했다.
- 느린 연결 장면 7.03초의 내려가는 중간 자세에서 실제 일시정지 버튼을 눌렀다. 구도를 바꾸는 동안 시간과 자세가 유지됐고, 재개 후 7.16초로 이어지는 것을 확인했다.
- 같은 연결 장면 15.56초의 일어서는 중간 자세에서 다시 멈춘 뒤 처음부터를 눌러 0.00초·두 발 시작 자세와 시작 위치로 돌아가는 것을 확인했다.
- 중간 자세를 정면·측면·후면·비스듬한 구도와 가까운/축소 화면에서 확인했다. 몸을 낮춘 모습과 앞발을 내리는 흐름이 구별되고 확인한 화면에서 심한 관절 분리나 전체 형태 붕괴는 보이지 않았다.
- 어깨·목·무릎·복장의 미세한 접힘과 발 접촉의 자연스러움은 사용자 동작 검토 대상으로 남긴다. 시점별 화면 관찰과 자동 궤적 검사만으로 모든 프레임의 미끄러짐이 없다고 단정하지 않는다.

## 사용자 확인과 다음 순서

Unity 상단의 **연결 장면 재생**으로 내려가기·일어서기, 출발·정지의 자연스러움을 확인한다. 정지 상태라면 **재생**을 눌러 진행한다. 이 결과 사용자 승인 전에는 2-3 완료나 신남·호기심 제작 착수를 기록하지 않는다.
