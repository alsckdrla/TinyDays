# v0.141 주민 이름·성향 표시

2026-10-05. 자율 생활 장면의 표시 보완이며 3-3 전체 품질 승인은 별도다.

## 구현

- 메뉴가 보이면 모든 활성 주민의 머리 위에 이름과 성향을 두 줄로 표시한다. 주민 번호와 현재 시뮬레이션 성향을 사용한다.
- 일반 이름표는 배경 없는 밝은 글자와 짙은 외곽 그림자다. 선택 주민의 이름 줄에만 65% 불투명도의 짙은 박스를 표시한다. 성향 줄에는 박스가 없다.
- 머리 높이는 현재 스킨 메시 범위로 계산한다. 귀가해 외형이 비활성화되거나 화면 밖이면 표시하지 않는다. 목록 열림 시 기존 이름표 클릭 영역을 두 줄 전체에 맞춘다.
- 메뉴 숨김에서는 표시하지 않고, Home/전체 보기에서는 선택 박스만 해제한다. 기존 비교 농가의 이름표·생활 판단·카메라 입력·원본 자산은 유지한다.

## 검증

- Logs/life141-build.log의 LIFE140_PLAYER_OK(기존 빌드 함수 표식)·종료0으로 컴파일 및 Windows 빌드 성공을 확인했다. 표시 변경에 별도 생활 6일 검사를 수행한 것으로 기록하지 않는다.
- 실제 1280×800에서 목록을 닫은 상태의 세 주민 이름·성향, 일반 클릭 선택, 다른 주민 더블클릭 따라보기와 선택 박스 이동, Home 복귀 후 일반 표시 유지, 메뉴 숨김/복원을 확인했다.
- 실제 800×600에서 낮·밤 두 줄 가독성 및 잘림 없음을 확인했다. 밤 0시로 고정한 뒤 주민 세 명이 귀가해 외형이 숨겨질 때 이름표도 모두 사라졌다.
- 실제 600×900 전체 보기에서 이름·성향 두 줄의 잘림 없음을 확인했다. 추가 목록/이름표 클릭 검사는 사용자 입력 감지로 두 번 중단됐으며 결과를 완료로 처리하지 않는다.
- 기본 원본·기존 아트/장면·프로토타입 829개 파일의 SHA256을 다시 확인해 변경0이다. git diff --check 통과. 이번 장면/아트 재생성은 하지 않았다.
- 창에서 주민이 서로 가까워지면 이름표가 겹칠 수 있다. 이름표 겹침 회피 기능은 이번에 추가하지 않았다. 기존 작은 조작 안내 글씨의 최종 품질은 별도다.
