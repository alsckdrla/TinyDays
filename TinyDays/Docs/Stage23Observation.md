## 제작 결과

승인한 정지 외형은 유지하고 기존 10클립의 움직임을 보완했다. 두 발 걷기는 좌우 지지와 짧은 공중 구간을 가진 총총걸음, 네 발 이동은 낮은 준비와 큰 도약·착지 반동으로 변경했다. 내려가기와 일어서기는 각각의 발 접촉 순서와 엉덩이 반동을 사용한다. 출발·정지, 머리·귀·꼬리의 뒤따르는 움직임을 연결했다. 대기는 호흡과 귀 움직임을 보완했다.

걷기 1.2초/0.36m, 깡충 이동 1초/0.30m, 대기 3초, 내려가기 1.2초·일어서기 1.4초, 출발/정지 0.6초와 각 누적 이동량은 이전 검토값을 유지한다. 본게임 수치가 아니다. 연결 장면과 개별 선택의 구분, 반복/단발 처리 및 검토 조작을 유지한다. 외형 재디자인·신남·호기심·소품·자율 판단은 이번 범위에 없다.

## 실제 Unity Game 창 재검증

초기에는 사용자 입력 감지로 조작을 중단했다. 사용자가 검증 가능한 시점을 알려준 뒤 최신 창 상태를 다시 확인하고 실제 Play 모드 검증을 완료했다. QHD 2560×1440 설정, 표시 배율 약 0.86에서 확인했으며 이전 버전이나 배치 검사 결과로 대체하지 않았다.

- 정상 1× 연결 장면에서 깡충 이동이 표시되고, 완료 후 마지막 두 발 대기를 유지하는 것을 확인했다.
- 0.5× 총총걸음의 7.28초 지점에서 정지해 양쪽 발과 바닥 사이의 공중 간격을 확인했다. 같은 자세를 정면·측면·후면·비스듬한 방향과 가까운/축소 크기로 확인했다.
- 느린 연결 장면 7.33초의 두 발→네 발 중간 자세에서 일시정지했다. 앞발 지지와 엉덩이 반동을 비스듬한·측면 구도로 확인했고 구도 변경 중 시간과 자세가 유지됐다.
- 재생 버튼을 누르면 7.45초로 이어졌고, 네 발 이동 이후 일어서는 구간까지 진행했다. 15.87초에서 다시 정지해 뒷발 지지와 몸을 일으키는 자세를 확인했다.
- 전환 중 처음부터 버튼을 눌러 0.00초·두 발 대기와 시작 위치로 돌아가는 것을 확인했다.
- 확인한 화면에서 심한 관절 분리나 전체 형태 붕괴는 보이지 않았다. 겨드랑이·복장 가장자리의 미세한 접힘과 동작 과장 정도는 사용자 검토 대상으로 남긴다. 정지 화면과 궤적 검사가 모든 프레임의 미끄러짐 부재나 자연스러움을 보증하지 않는다.
