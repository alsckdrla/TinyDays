# 2-6 농가·임시 생활 장면 확인 기록

검증일: 2026-09-15. Unity 2022.3.20f1 / URP 14.0.10. 캐릭터와 기존 Blender 5.2.1 원본·동작은 수정하지 않았다.

## 구현과 자동 검사

- 맑은 봄 낮, 집 2채·창고·밭·쉼터·흙길·울타리·나무·생활 소품과 임시 토끼 6명을 별도 `FarmStudy` 장면으로 구성했다.
- 주민 위치·활동, 교체 가능한 외형·동작 재생, 장면 공용 검토 UI를 분리했다. 작업 지점은 기존 대기로 표현한다.
- Unity 컴파일·URP 장면 생성, 주민별 독립 Animator, 전체 경로의 건물 여유 공간·주민 간 거리, 반복 생성의 `ManualEdits` 보존 검사를 통과했다. 수치는 [자동 검사 기록](Stage26Verification.txt)에 보존한다.
- `Layout-*-view*.png`는 네 방향 및 1440×900·800×600·600×900 구도의 자동 렌더다. 실제 작은 Game 창의 입력·가독성 확인을 대신하지 않는다.

## 실제 Unity Game 창 확인

- Play 모드에서 6명에게 기존 걷기·대기가 표시되고, 서로 다른 시점에 이동·머무르기가 이어지는 것을 확인했다.
- 네 고정 방향, 전체/가까이 보기, 다음 주민 선택과 따라보기 버튼을 확인했다.
- 일시정지 시 시간과 위치가 유지된다. 정지 중 처음부터를 누르면 0초와 주민별 초기 위치로 돌아가며 정지를 유지한다. 재생으로 다시 진행한다.
- 메뉴 숨김과 왼쪽 위 메뉴 복원 버튼을 확인했다.
- 기본 구도에서 주민의 실루엣과 이동을 읽을 수 있다. 반대·옆 구도에서는 건물과 나무 뒤의 주민이 일시적으로 가려진다.
- 연속 관찰: 한국 시간 12:17:03.902~12:22:25.636, **321.734초(약 5분 22초)** 동안 배속·일시정지·초기화 없이 실행했다. Game 표시도 0초에서 322초로 증가했다. 이동과 대기가 한 주기를 넘어 계속 이어졌고, 관찰 표본에서 건물 관통·주민 겹침·영구 정체는 보이지 않았다. 실제 시각은 [캡처 기록](Stage26CaptureLog.json), 마지막 화면은 `Captures/Stage26/Game-Continuous-Final.png`에 보존했다.
- 현재 실행 로그에서 스크립트 예외나 컴파일 오류가 검색되지 않았다. 원본 104개 파일의 해시와 프로토타입 기존 변경 내역도 작업 전과 일치한다.

증거 이미지는 `Captures/Stage26/Game-*.png`에 보존한다. `Game-Pause`, `Game-Restart-Paused`, `Game-Focus-Resident2`, `Game-HideMenu`는 실제 검토 버튼을 사용한 상태다.

## 남은 확인과 한계

- **실제 작은 Game 창 확인은 미완료다.** 기존 최대화 Game 패널을 전환할 때 Unity가 레이아웃 백업 누락과 전체 레이아웃 초기화 대화상자를 표시했다. 초기화에 동의하지 않았으며, 다시 연 기존 창에서 검증을 계속했다. 관련 로그와 레이아웃 사본은 `Logs/farm-study-layout-interruption.log`, `Logs/Stage26LayoutBackup`에 보존했다.
- 장면은 같은 순환 경로에 주민별 시차를 둔 연출이다. 동시 시작은 피했으나 이동 경로와 대기 순서는 반복해서 드러난다. 실제 생산·자원·피로·자율 판단이나 새로운 작업 애니메이션은 없다.
- 농가 자산·빛과 토끼 외형·동작은 검토용이다. 과장되고 사랑스러운 캐릭터 동작이라는 사용자 목표를 달성했다고 기록하지 않는다.
- 이번 관찰은 연출 장면의 5분 검사다. 본게임 장시간 안정성, Windows 실행 파일, 저장·복원, 16× 성능 검사와 구분한다.
- 농가 배치와 생활 밀도에 대한 **사용자 확인은 대기**한다. 캐릭터 최종 품질 승인을 요청하는 단계가 아니다. 장면 확인 뒤 2-7의 빛·카메라 계획을 합의한다.
