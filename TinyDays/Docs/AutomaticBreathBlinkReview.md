# 자동 기본 호흡·눈 깜빡임 검토

2026-10-02 · v0.125 · 사용자 확인 대기

- 기본 원본은 `ArtSource/AdultRabbit - 01.blend`. 원본/FBX/액션 곡선은 이번 작업에서 재생성하지 않는다.
- 동작 검토의 서기·앉기와 누운 연속 호흡, 물뿌리개 운반 대기와 벤치 호흡은 기존 경로를 사용한다. 공통 얼굴 제어에는 몸 호흡을 넣지 않아 중복되지 않는다. 외형 검토의 기본 자세에만 4초·14mm 가슴 이동을 추가했다. 걷기/달리기/물 주기/전환 몸동작은 유지한다.
- `AdultFaceMotion`은 3.2/3.6/4.0/4.4초 중 직전과 다른 간격을 시드로 선택한다. 감기0.08/닫힘0.03/뜨기0.13초, 최소가속도형 곡선이다. 주민별 `blinkSeed`를 다르게 설정할 수 있다.
- 몸 샘플링 후 `SleepEyesClosed`를 최종 합성하고 LateUpdate에서 재확인한다. 수면 채널은 별도로 유지하며 잠들기/수면/깨어나기 동안 깜빡임을 억제한다. 깨어나기 완료 후 새 간격을 기다린다. 없는 얼굴 기능은 생략한다.
- 동작 선택/생활 모드 변경은 얼굴 시간을 보존한다. 재생 배속/일시정지에 따른다. 주요 포즈는 일시정지된 값을 유지한다. 생활의 명시적 처음 위치는 새 시드 시간으로 초기화한다.
- Blender Text Editor에서 `Tools/preview_adult_blink.py`를 실행하면 같은 시드 선택과 곡선을 미리 볼 수 있다. 기존 `tiny_sleep_eye`가 있으면 수면 값을 합성한다. 자동실행을 활성화하지 않은 파일은 `tiny_blink_sleep_weight`/`tiny_blink_sleep` 설정으로 수면 미리보기를 지정한다. 미리보기 핸들러는 드라이버를 잠시 mute하므로 기본 원본에는 저장하지 않는다. FBX별로 굽지 않는다.

## 검증 구분

`AutomaticFaceVerification.txt`, `Logs/automatic-face-latest.log`에 자동 결과를 남긴다. 네 간격/곡선/30·60·120fps×0.5·1배/일시정지/억제/깨어난 뒤 대기를 통과했다. 실제 가져온 셰이프의 걷기 중 적용·수면 닫힘과 동작/생활 모드의 시간 보존을 확인했다. 기존 240Hz 출입·20왕복·96걷기/달리기 정지 조합, 물 주기·벤치 접지 회귀도 통과했다. Blender5.2.1 미리보기 자체 검사 `BLINK_PREVIEW_OK`다.

외형·동작·생활 Windows 빌드는 성공했으며 Data 갱신은17:26:09/17:26:14/17:26:17이다. 그래픽 플레이어의 패널/출입/물 주기/벤치 자동 스모크4개 종료0(`Logs/blink-*-player.log`). 이 결과는 실제 마우스 입력이나 사용자 품질 승인이 아니다. 이번 새 깜빡임의 확대 렌더/전후 영상 검토와 모든 수면·전환 요청 조합의 재검사는 완료했다고 주장하지 않는다. 사용자 실행 확인이 남아 있다.

## 사용자 확인
