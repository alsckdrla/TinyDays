# v0.142 저장·이어하기

2026-10-05. 3-3과 주민 이름·성향 표시는 사용자 진행 승인으로 기록한다. 기존 캐릭터 세부 품질 보완과 2단계 미완료는 보존한다.

## 저장 기준

- 자율 생활 검토 전용 JSON 한 슬롯. Application.persistentDataPath/AutonomousLife/AutonomousLife142.json에 실제 60초마다 변경분과 정상 종료 상태를 저장한다. 재실행 시 본 저장 또는 정상 백업으로 이어간다. 오프라인 시간 계산은 없다.
- 주민 행동/경로/진행량/욕구/성향/대기·복구, 작물/열매·공동 식량·물품과 바구니 소유, 자리/생산/식사/회수 예약, Day/시각/자동·고정/하루 길이/배속/정지, 카메라/선택·따라보기/메뉴 숨김을 저장한다. 패널·드래그는 닫는다. 조명 색상과 그림자 설정은 기존 방식이다.
- 버전/체크섬·장면/검토값 식별과 상태 유효성을 검사한다. 후보 시뮬레이션 전체를 검증한 뒤 실제 생활에 적용하며, 잘못된 불러오기는 현재 생활을 유지한다.
- 임시 파일을 디스크에 쓰고 다시 읽어 검증한 뒤 원자적으로 본 저장을 교체한다. 직전 정상 본 저장이 .bak이 된다. 손상 파일은 확인한 새 저장으로 교체할 때 .unreadable.* 복사본으로 보존한다. 손상 본 저장으로 정상 백업을 덮어쓰지 않는다.
- 둘 다 읽을 수 없으면 초기 농가를 유지하고 자동 저장을 차단한다. 화면/설정창 안내 후 저장 또는 처음부터의 확인을 받아 새 저장을 만든다. 저장 실패도 안내한다.
- Esc 설정에 저장/불러오기와 결과를 추가했다. 짧은 창은 버튼을 줄이지 않고 설정 내용만 스크롤한다. 처음부터 확인/취소 모달과 저장 실패 후 확인 모달은 카메라·주민 선택 입력을 막는다.
