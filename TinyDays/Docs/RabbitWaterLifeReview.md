# 외출·물뿌리개 집기·물 주기·제자리 내려놓기 — v0.126

2026-10-02 · 사용자 확인 대기

후속 v0.127의 선택 가능한 벤치 휴식 연결은 `RabbitWaterBenchLifeReview.md`를 따른다. 아래 물 주기까지만 흐름은 보존하며 벤치 연결 제외는 v0.126 당시 범위다.

## 흐름과 조작

- `RabbitHomeLifeStudy`/`TinyDaysRabbitHomeLife.exe`의 왼쪽 패널에서 **생활 흐름 · 외출해서 물 주기**를 선택한 뒤 **전체 흐름 · 외출해서 물 주기**를 누른다.
- 실내 대기 → 기존 자동문 외출/문 닫힘 대기 → 문 오른쪽 물뿌리개로 이동 → 집기 → 기존 운반 걷기 → 물 주기 → 보관점으로 돌아오기 → 내려놓기 → 밖에서 서기 대기다. 최초 흐름은 약27.87초다.
- 문 오른쪽 바닥의 보관점/접근점/화단 작업점은 별도 Transform이다. 실제 소품 메시 최저점을 사용해 바닥 여유2.5mm로 배치한다. 보관점X는 최소0.7m, Z−3.7m, 접근점Z−4.06m이며 문 통과 경로를 비운다. 작업점은 기존 화단 앞1.3/−3.7m, 방향90도다.
- 집기/내려놓기각1.8초·54프레임. 몸을 낮춘 뒤 양손 접촉, 들어올리기 또는 바닥 지지 후 손 회수로 연결한다. 원본 팔/다리 길이를 늘리지 않는다. 기존3개 작업 클립 뒤에2개를 추가해 작업 소스는41액션이다.
- 기존 개별 출입/물 주기/벤치 검토는 유지한다. 생활 흐름에서는 현재 위치의 운반 진입을 사용하므로 모드 초기화처럼 주민을 이동시키지 않는다. 몸/소품의 소유자는 단계별 하나다.
- 정지는 보행 감속/물 주기0.5초 복귀를 요청하며 출입·집기·내려놓기와 진행 중인 안전한 발 디딤은 끝낸다. 현재 위치에서 대기하고 자동 귀가/보관점 복귀를 하지 않는다. 재생을 다시 누르면 중단 위치에서 이어간다. 완료 후 다시 누르면 실외에서 물 주기를 반복하며 자동 귀가하지 않는다.
- 초기화는 실내/문 닫힘/소품 원위치/물 효과 꺼짐으로 복귀하며 얼굴 시간도 정리한다. 검토 모드 변경에는 얼굴 시간을 보존한다. 주요8포즈·배속·일시정지·카메라·스크롤을 유지한다.

## 보존·검증

- 기본 원본`AdultRabbit - 01.blend` SHA256625909966788c99c8dc62e5160bca7fa9390e6b82e580d48596db6deec59c531 유지. 저장된 작업 소스를 다시 읽어 기존39개 액션/메시/셰이프키/가중치/재질/바인드 보존을 확인했다. 백업`ArtSource/Backups/WaterFlow20261002`, 기록`WaterPickupPreservation.json`/`WaterLifeSavedPreservation.json`.
- 초기20회 반복에서는 짧은 거리를 이동하지 않던 조건으로 집기점이 약10cm 어긋나 팔 도달 실패가 발생했다. 가까운 거리는 낮은 두 걸음으로 정리하도록 수정했다. 정확한 위치에 순간 이동하거나 잔걸음을 반복하지 않는다.
- 기본 흐름은240Hz 내부 계산으로30/60/120fps×0.5/1배와20회 위치 초기화 없는 물 주기 반복을 통과했다. 지정 손잡이 앵커 오차0.349mm/팔 도달 초과0/신발 최저+2.110mm/지지 간격2.803mm/고정발 이동0.389mm/최종 소품 위치 오차0을 기록했다. 실제 손 표면 전체의 충돌 검사는 아니다.
- 초기 소품 인계에서4.837mm 위치 차이를 발견했다. 현재 소품 위치를 보존한 뒤0.25초 동안 운반 위치로 연속 연결하여 최종 인계 순간 위치 차이0을 확인했다. 이 수치가 자연스러움의 사용자 승인을 대신하지 않는다.
- 단계별 정지/중복 요청/재개·일시정지·모드 정리/얼굴 시간 보존 및 기존 출입240Hz·20왕복·걷기/달리기96정지 조합·물 주기/벤치 회귀 통과. 명시적 실내 초기화로 매번 외출하는20회 전체 루틴도 통과했다. 최종 검사/렌더/Windows 빌드는 `Logs/water-life126-final2.log`의 `WATER_LIFE_FINALIZE_OK`, 그래픽 플레이어 전체 흐름 자동 실행은 `water-life126-player.log`의 `WATER_LIFE_PLAYER_OK`/종료0을 확인했다. 이는 직접 OS 마우스 입력이 아니다.
- 주요8포즈×두 동작×세 구도48장과 얼굴 쪽 추가16장, 세 구도836프레임씩/30fps의1×영상은`Captures/RabbitWaterLife`다. 연속 영상은 자동 렌더이며 직접 OS 입력 녹화가 아니다. 대표 포즈를 시각 확인했으며 자연스러움의 사용자 승인은 남아 있다.

## 재개

- `Tools/RebuildRabbitWaterLife.ps1`은 기존 작업 소스에두 클립만 갱신하고 장면/검사/렌더/Windows 빌드/영상 인코딩을 실행한다. 아트 반영 완료 후에는`-SkipArt`를 사용한다. 기본 원본과 기존 Motion/Home/Bench 소스에 저장하지 않는다.
- Blender 작업 소스의`WaterPreview.py`를 명시적으로 실행하면 집기/내려놓기 소품 경로도 미리 볼 수 있다. 사용자 자동실행 설정은 바꾸지 않는다.
- **외출·물뿌리개 집기·물 주기·제자리 내려놓기 사용자 확인 대기**. 실제 마우스 입력과 사용자 품질 확인은 자동 검사/렌더와 구분한다. 물 채우기·꽃마다 이동·귀가/벤치 자동 연결·생활AI·농가 적용·상의–다리 미세 보완·GitHub는 제외했다.
