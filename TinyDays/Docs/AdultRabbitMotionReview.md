# 성인 토끼 두 발 대기·걷기 검토

## v0.82 — 자연스러운 출발·발 모으기 정지 사용자 확인 대기

- 이전의 별도 체중 이동 준비를 없애고, 대기에서 첫걸음을 내디디며 약 0.45초에 정상 걷기로 연결한다. 골반 높이 보정의 변화 속도와 해제를 완만하게 하고 작은 도달 거리 보정을 두 관절에 분산한다. 보정은 전환 구간에서 해제되며 원본 정상 걷기 클립은 그대로다.
- 정지는 감속 → 마지막 발 착지 → **앞발 고정, 뒷발 1.5cm 들기·0.3초 정리걸음** → 양발 접지/앞뒤 정렬 확인 → 0.15초 안정이다. 몸도 최종 발 중심으로 이동한다. `발 모으기`를 표시하며 이미 앞뒤 차이가 1cm 이내면 생략한다. 수동·자동 정지가 같고 자동 정지 시작은 5.25m다. 발 모으기 중 재출발은 현재 위치에서 이어진다.
- 짧은 정지 직후 재출발에서 선형 감속이 지지발의 허용 이동량을 초과하던 오류를 발견했다. 끝 속도를 0으로 제한하는 것만으로는 이동 거리가 줄지 않았고, 뒷발이 뒤에 남아 몸이 낮아지고 코트 보정이 커졌다. 필요한 경우 연속 비선형 감속을 사용해 허용 이동량을 지킨다. 코트 보정의 6.5cm 검토 한도를 느슨하게 바꾸지 않았다.

### 자동 검사

- 수정 전 `AdultRabbitStartBeforeV082.csv`, 수정 후 `AdultRabbitStartMotion.csv`: 0~1.65초 240Hz에서 골반 높이 범위 100.474 → 67.380mm, 최대 상하 속도 1.449137 → 0.444403m/s, 머리 최대 상하 속도 1.449537 → 0.444489m/s. 수치는 초기 추가 반동의 감소 근거이며 자연스러움 승인은 아니다.
- 발 모으기: 8위상·295표본, 도중 재출발 24경우 통과. 양발 최종 앞뒤 차이 0(보고 정밀도), 들린 신발 바닥 최대 17.500mm(기본 +2.5mm 포함). 이 검사에서 추가 관절 길이 보정 최대 1.31%. 정지 806표본의 신발 바닥 +2.499~2.500mm, 무릎 정렬 이탈 최대 0.083mm.
- 접지 48조합과 반복 입력 15경우 통과: 지지발 이동 약 0.001mm, 최저 신발 +2.443mm, 도달 불가 0, 프레임률/배속 간 이동 거리 차이 11.042mm. 일시정지·초기화·클립 복귀·콜백 직접 호출·0초 재평가 회귀 통과.
- 코트는 기존 2,748시점을 그대로 두고 발 정리/재출발 1,472시점을 추가했다. 총 **4,220시점 중 1mm 초과 0**, 최대 실행용 보정 41.575mm. 원본 코트와 실행용 보정 방식은 변경하지 않았다. 전면 광선/정점 표본이므로 모든 방향의 교차 없음 보증은 아니다.

## v0.81 — X자 무릎·양발 정지 자세

사용자 피드백으로 v0.80의 무릎 방향 보정을 철회했다. 전방 고관절–발목 평면에서 무릎을 계산하고, 전환 골반과 좌우 다리 길이를 맞춘다. 왼발 최초 출발을 고정하고 재출발을 0.06초로 압축하던 처리를 없앴다. 현재 발 위치에서 0.3초 내딛기와 가능한 가속으로 연결한다. 정상 걷기 클립·카메라·원본 코트·농가는 유지한다.

- 정지는 감속 → 들린 발 착지 → 양쪽 신발 바닥 개별 확인 → 약 0.15초 안정 → `정지 완료` 순서다. `착지 중`과 `양발 안정 중`을 별도 표시한다. 조금 앞뒤로 벌어진 양발 정지는 허용하지만 한 발이 떠 있는 자세를 완료로 간주하지 않는다.
- **재현 한계:** v0.80 출발·정지 X자 자세는 좌표·렌더에서 확인했다. 그러나 확인한 이전 자동 정지(8초)에서는 양쪽 신발이 +2.5mm였으므로 그 장면의 한 발 공중 정지는 재현되지 않았다. 이전 최저 바닥 검사는 두 신발을 합친 최솟값이어서 개별 들뜸과 무릎 정렬까지 보장하지 못했다. 원본 좌표 `AdultRabbitPostureBeforeV081.txt`, 이미지 `Captures/AdultRabbitMotionBeforeV081/Posture*`를 보존한다.
- 무릎을 정상 방향으로 바꾼 중간 버전에서 코트 248시점·최대 46.65mm 관통이 재발했다. 사용자 추가 승인으로 **실행 중 옷감 보정**을 추가했다. 원본 자산은 유지하고 코트의 복제 메시에서 전면 교차 부근을 밀어낸다. 주변·안감에 공간 감쇠를 적용하고 초당 0.3m로 원상 복귀한다. 물리 시뮬레이션·추가 뼈·새 재질이나 렌더러는 없다.
- 처음 구현의 안감 중복 교차는 불필요한 큰 보정을 만들 수 있어 가장 앞쪽 옷감 표면만 사용하도록 수정했다. 바깥 보정은 관통을 피하려고 즉시 적용하므로 연속 재생에서 옷감 반응의 자연스러움은 사용자 확인이 필요하다. 저사양 성능 측정은 하지 않았다.
- 복제 메시 정리는 초기화·클립 전환·OnDisable에서 원본 참조 복원으로 검사한다. 편집 모드의 콜백 직접 호출은 실제 Game 창의 비활성화 입력과 다르다. 자동 수치/정지 렌더/실제 입력/사용자 승인을 구분한다.

최신 자동 수치는 `AdultRabbitMotionVerification.txt`, `AdultRabbitPostureVerification.txt`, `AdultRabbitTransitionVerification.txt`를 따른다. 무릎 좌우 이탈 0.083mm, 무릎 간격 최소 288.859mm, 정지 1,098표본의 각 신발 바닥 +2.499~2.500mm. 48개 접지 조합·15개 반복 요청, 코트 2,748시점 검사를 유지한다. 전면 광선/정점 표본 검사는 모든 방향의 메시 무관통 보증이 아니다.

최종 회귀 통과: 코트 1mm 초과 0/2,748시점, 실행용 옷감 최대 변위 49.647mm(`dense restart 7/0.300/36`). 초기화 3회·클립 복귀·비활성화 콜백 호출에서 원본 참조 복원과 정점/삼각형/재질 수 보존을 확인했다. 편집 모드 SendMessage assertion을 피하도록 검증은 콜백을 직접 호출하며 실제 Play Mode 검사는 아니다. 변경 없는 부위의 원본 스무스 노멀도 유지한다.

Windows v0.81 빌드 성공: `Logs/AdultRabbitMotionPlayer/TinyDaysAdultRabbitMotion.exe`, 확인 로그 `ADULT_RABBIT_MOTION_OK` / `ADULT_RABBIT_MOTION_PLAYER_OK`. 정면·측면의 `Posture0.30*`, `Posture0.65*`, `Posture8.00*`, 최대 옷감 보정의 `CoatCorrectionMaxFront/Side/Quarter`를 검토했다. 무릎 교차와 검사 장면의 코트 전면 돌출은 보이지 않지만, 밑단의 변화와 연속 반응은 사용자 확인이 남는다. GitHub 업로드 없음.

사용자 확인 순서: `이동 검토 / 처음 위치` → 출발 첫 세 걸음 → 수동 정지 → 감속 중 출발/정지 반복 → 경로 끝 자동 정지. 0.5×와 1×에서 정면의 무릎 정렬, 측면의 양발 착지, 옷감의 튀는 변화·관통을 확인한다. **출발·양발 정지 자세 사용자 확인 대기**다. 아래 버전은 당시 기록이며 최신 동작 기준이 아니다. 실제 프로그램 입력·연속 품질은 아직 미검증이다.

## v0.80 — 전환 코트 보완·사용자 확인 대기

코트와 원본 걷기를 수정하지 않고 런타임 전환을 보완했다. 착지한 골반·다리 길이 기준을 유지한 채 상체가 대기로 돌아가며, 재출발에서는 현재 자세를 연속적으로 풀어 원본 걷기로 연결한다. 전환 중 무릎 굽힘 방향 제한은 첫 보행 주기 뒤 해제한다. 이전 프레임의 IK 결과는 다음 애니메이션 평가 전에 복원한다.

- 확대 검사 **2,748시점**: 보정 전 288시점에서 1mm 초과·최대 66.72mm → 수정 후 검출 0. 원본 317시점 외에 완전 정지·첫 보행 주기·재출발 후 재정지까지 검사했다. 전면 광선/정점 검사이므로 모든 메시 교차의 수학적 증명은 아니다.
- 접지 48조합, 반복 입력 15조합, 일시정지·초기화·클립 복귀 통과. 지지발 이동 약 0.001mm, 최저 신발 +2.499mm, 도달 불가 0. 다섯 번 초기화한 같은 입력과 0초 재평가에서 메시 차이가 보고 정밀도상 0이다. 실제 게임 입력 검증은 아니다.
- [수정 전 기록](AdultRabbitMotionBeforeV080.txt) / [수정 후 기록](AdultRabbitMotionVerification.txt). 이전 18.85mm와 확대 검사 66.72mm는 표본 범위가 다르다.
- 같은 입력 순서의 [수정 전 정면](Captures/AdultRabbitMotionBeforeV080/TransitionRestartFront.png) / [수정 후 정면](Captures/AdultRabbitMotion/TransitionRestartFront.png), [측면](Captures/AdultRabbitMotion/TransitionRestartSide.png), [비스듬한 구도](Captures/AdultRabbitMotion/TransitionRestartQuarter.png)에서 무릎 돌출 해소를 확인했다.
- Windows 실행 파일: `Logs/AdultRabbitMotionPlayer/TinyDaysAdultRabbitMotion.exe` (v0.80). 빌드 성공. 기존 모델·Blender·FBX·생성 스크립트와 농가 보존 확인, GitHub 업로드 없음.
- 실행 프로세스 응답과 시작 로그의 오류/예외 없음을 확인했다(`Logs/adult-rabbit-motion-player-v080-startup.log`). 실제 화면 입력 검증이나 동작 품질 승인으로 해석하지 않는다.

사용자 확인: `이동 검토 / 처음 위치` → 출발 → 정지, 감속 중 출발, 다시 정지를 0.5×와 1×로 확인한다. 정면/측면에서 코트 관통·발 고정·벌어진 정지 자세가 자연스러운지 확인한다. 실제 버튼·마우스 조작과 연속 동작 품질은 미검증이며 **출발·마지막 한 발 정지 사용자 확인 대기**다. 아래 v0.79의 시각 회귀 미완료 표기는 당시 기록이다.

## v0.79 — 마지막 발 정지: 시각 회귀 보완 필요

`이동 검토 / 처음 위치` → `출발` → `정지`에서 새 상태 전환을 검토한다. 오른발 체중 이동 0.15초, 왼발 출발·가속 약 0.3초, 정상 1.15m/s. 정지는 들린 발을 마지막으로 착지시키고 상체를 0.15초 안정시킨다. 두 발 접지 상태에서는 새 걸음을 시작하지 않는다. 감속 중 출발은 현재 발 위치와 걷기 위상에서 이어진다. 상태와 지지발이 화면에 표시된다.

기존 뼈에 두 관절 IK를 적용하고 지지발을 세계 좌표에 고정한다. 원본 클립·FBX·Blender·코트는 유지하며 런타임 보정만 추가했다. 1/240초 적분과 두 배속을 함께 적용한다. 평평한 검토 지면 전용이며 농가에는 적용하지 않았다.

- 정지 48조합(8위상×3프레임률×2배속): 지지발 이동 최대 0.726mm, 최저 신발 바닥 +2.499mm, 도달 불가 0, 총 거리 차이 최대 4.792mm.
- 출발 중 정지·재출발·반복 요청 15조합: 이동 최대 0.884mm, 최저 +2.499mm, 도달 불가 0. 수치는 실제 이동 좌표의 직접 함수 호출 결과다.
- **미해결:** 코트 전면 검사 317시점 중 28시점에서 1mm 초과, 최대 18.85mm(`restart 7/6`). 정면 렌더에 무릎 돌출이 남는다. 접지 통과만으로 시각 품질 완료를 표시하지 않는다. v0.78 코트는 사용자 확인 완료이나 새 전환 자세는 수정 필요다.
- Windows 동작 검토 빌드는 성공했지만 시각 회귀가 남은 개발 중 빌드다. `Logs/adult-rabbit-motion-player-build.log`의 `ADULT_RABBIT_MOTION_PLAYER_OK`와 검사 결과의 `INCOMPLETE`를 함께 해석한다.
- 일시정지·초기화·클립 변경과 OnDisable 콜백 직접 호출을 검사한다. 실제 Play Mode 비활성화·재활성화와 프로그램 마우스 입력은 별도 미검증이다.
- 최신 자세: `Captures/AdultRabbitMotion/Moving_*.png`, 관통 재현: `CoatWorstFront/Side/Quarter.png`. 수정 전 코트 검사·캡처는 `AdultRabbitMotionBeforeV078` 기록을 보존한다.

## v0.76 — 실제 이동과 전환

검토 프로그램의 `이동 검토 / 처음 위치` → `출발` → `정지`로 확인한다. 0.3초에 걸쳐 대기/걷기를 혼합하며 걷기 위상 증가량과 이동 거리를 연결했다. 정상 속도 1.15m/s·한 주기 0.92m다. 0.5×는 양쪽을 함께 절반으로 늦추며 일시정지는 모두 멈춘다. 약 6m에서 자동 감속하고, 처음 위치 버튼으로 다시 시작한다. 카메라가 주민을 따라간다.

직접 호출 자동 검사는 이동 거리·가속/감속·정지·재출발·배속·정지 후 드리프트·혼합 메시 변화를 포함하며 통과했다. 측면 전환 렌더는 `Captures/AdultRabbitMotion/Moving_*.png`. 실제 입력 및 연속 전환 품질은 사용자 확인 대기다. 혼합 구간에는 별도 발 고정이 없어 미끄러짐·들뜸이 남을 수 있으며 정상 보행의 접지 검증과 구분한다. 별도 전환 클립은 제작하지 않았다.

## v0.75 — 접지·리듬

v0.74의 팔·하이라이트는 사용자 확인 완료. 발 지지 구간은 몸 기준 등속 후방 이동, 회수 구간은 속도가 이어지는 곡선이며 골반 변화 뒤 다리를 다시 계산한다. 실제 신발 정점 기준 높이와 고정된 좌우 위치를 사용한다. 몸 상하 극값 ±0.030m, 0.8초 반복을 유지한다.

양발 96시점의 신발 정점·지지 궤적을 검사한다. 제자리 보행은 가상 전진 0.92m/주기(1.15m/s)를 보상하여 미끄러짐을 측정하며 실제 농가 속도 연결 검증이 아니다. 수정 전 바닥 침범 5.30mm·보상 지지발 이동 40.89mm는 `AdultRabbitMotionBeforeV075.txt`에 보존했다. 최신 결과는 `AdultRabbitMotionVerification.txt`를 따른다. 실제 연속 동작·사용자 승인은 별도 대기다.

## 범위

- `AdultStandard_v2`의 두 발 대기와 두 발 걷기를 수정했다. 네 발 대기·낮은 깡충 이동은 기존 클립을 유지했다.
