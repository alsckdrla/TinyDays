# v0.30 그림자 품질 실제 확인

- 자동 검사: 세 URP 자산의 해상도·캐스케이드·소프트 섀도우·60m 거리, 기본값, 즉시 전환·로컬 저장 복원과 Esc 패널의 안내문 여백을 통과했다. 상세 결과는 `ShadowQualityVerification.txt`에 있다.
- 실제 Windows 최대화 창: 최대 줌아웃까지 진행해도 나무·집·울타리의 그림자가 유지되는 것을 확인했다.
- 실제 Windows 800×600: Esc 설정 패널의 안내문이 패널 안에서 완전히 표시되고, 기본 품질 선택을 확인했다.
- 성능 목표와 최소 사양은 아직 합의하지 않았다. 이 장면에서 선택 전환과 60m 거리에서 뚜렷한 체감 정체는 관찰하지 못했지만, 출시 성능 검증을 의미하지 않는다.

상태: **구현·자동 검사·실제 Windows 입력 확인 / 사용자 확인 대기**.
