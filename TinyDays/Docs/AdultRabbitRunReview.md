## 동작과 조작

- AdultStandard_v2 달리기 클립: 30fps·18프레임·0.6초 반복, 실제 이동 검토 2m/s. 지지 구간 40%와 짧은 양발 비접지 구간, 굽힌 팔의 반대 흔들림, 귀·목도리·배낭 후행을 사용한다.
- `이동 검토 / 처음 위치` → `달리기`로 시작한다. 기존 첫걸음 뒤 약 0.45초에 걷기에서 달리기로 전환한다. 이동 중 `걷기 / 출발`로 걷기로 돌아올 수 있다.
- `정지`: 감속·들린 발 착지 → 앞발을 고정하고 뒷발을 옆으로 정리 → 양발 접지·앞뒤 차이 1cm 이내 확인 → 안정·대기. 양발이 떠 있는 구간도 각각 착지시킨다. 달리기 자동 정지는 4.8m부터 요청한다.
- 상단 `두 발 달리기`는 제자리 검토다. 0.5×/1×, 일시정지, 8개 시점, 정면/측면/Home을 제공한다. 왼쪽 패닝·오른쪽 회전·가운데 높이·휠 줌·Q/E 높이 조작은 기존과 같다.
- 코트 원본은 유지하고 이동/제자리 달리기에서 실행용 옷감 보정을 사용한다. 모델 삼각형·재질·골격은 추가하지 않았다.

## 검증 기록

- 첫 검사: 48개 정지 조합·15,178시점에서 최저 신발 바닥 +2.499mm, 지지발 이동 약 0.001mm, 최종 발 앞뒤 차이 0(보고 정밀도), 무릎 간격 최소 286.002mm. 코트 전면 3,794시점의 1mm 초과 관통은 없었으나 보정량 67.294mm가 기존 65mm 상한을 넘어 미완료 처리했다.
- 이 실패에 따라 발 회수 높이를 15cm에서 13.5cm로 낮추어 재검증했다. 최종 보정 최대 62.758mm로 기존 65mm 상한을 통과했다.
- 최종 수치와 통과 여부는 `AdultRabbitRunVerification.txt`, 기존 걷기 회귀는 `AdultRabbitMotionVerification.txt`를 따른다. 자동 검사는 실제 Windows 입력과 사용자 동작 품질 승인을 대신하지 않는다.
- 최종 48조합·15,178시점 통과: 바닥 최저 +2.499mm, 고정발 이동 약 0.001mm, 정지 양발 앞뒤 차이 0(보고 정밀도), 무릎 간격 최소 286.418mm. 코트 전면 3,794시점 관통 검출 0. 요청 시점을 프레임으로 반올림한 이동 거리 편차 최대 62.497mm로 30fps 한 프레임 이동량 범위다.
